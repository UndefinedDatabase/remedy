# Remedy ist eingefroren

Remedy wurde am 14. November 2026 von seinem Betreiber eingefroren.
Es wird nichts mehr daran gebaut.
Der Code bleibt als Archiv lesbar.
Drei Ideen aus Remedy leben an anderer Stelle weiter.
Die erste ist der Plan mit regelmäßigem Aufräumen.
Die zweite ist die Regel, in einfachen Sätzen zu schreiben.
Die dritte ist die Berichtsschleife in Universe.
