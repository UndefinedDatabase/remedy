## Goal & Done
See ROADMAP.md F075; the Done criterion there is binding.

## Context (existing code & prior features)
Autonomy without proof is recklessness; this gate turns trust into data.

## Design
Definition of flawless: no operator command except start, verifier PASS, DoD green, 0 unclassified failures. `scripts/self_run_gauntlet.py`: 10 curated orders (small to M) run sequentially; result matrix to evidence/gauntlet/. Passing flips the F046 default via a config change WITH an ADR.

## Task slicing
T001 gauntlet harness + order set + matrix report. T002 iterate runs + fixes until 10/10 (multiple rounds expected - that is the point).

## Acceptance & tests
10/10 green and linkable; failures stay visible in the matrix (P6 - no cherry-picking).

## Risks / anti-goals
Never weaken the flawless definition to pass; weaken NOTHING - fix Remedy instead.
