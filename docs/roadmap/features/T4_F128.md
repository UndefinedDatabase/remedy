## Goal & Done

## Context (existing code & prior features)
Memory must prove the core does not secretly depend on it.

## Design
[memory] enabled=false empties the selector (attached_cards=[] everywhere), the UI shows a module-off state, nothing else changes; core imports memory ONLY through memory_api (import-linter contract in CI).

## Task slicing
T001 off switch + UI state + tests. T002 import-linter rule + core benchmark run with memory off.

## Acceptance & tests
Core benchmark unchanged when off; boundary violations fail lint.

## Risks / anti-goals
No hidden memory reads in the core.
