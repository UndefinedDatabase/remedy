## Why this exists
`do plan`, `do job-plan` and `job plan` are three separate operations whose names
claim kinship they do not have; `do` carries fifteen subcommands, `job`
twenty-eight, and the `job-*` hyphen family under `do` encodes a second grouping
level in a hyphen because the tree did not have one. A user who learns one of the
three learns the wrong thing about the other two. F259 decided the words and F260
made a job one thing; this feature is where the CLI starts saying so. The
operator's Level 4 test of 2026-09-05 met all of it at once: `remedy do` doing three
different things depending on flags, `--builder` meaning something other than
`--builder-provider`, and help text cut off mid-sentence.

## Design
- The catalog is the single place where a name lives; a rename is a catalog edit
  plus the handler wiring, not a scatter of string literals.
- One rename at a time, each with the canary green before the next starts. A batch
  rename that reds the canary cannot be bisected.
- Groups are deleted after their modules (F260 deleted the prototype cluster;
  this feature deletes the catalog groups D4 lists and any handler F260 left).
  `queue` and `loop` are deleted here with their modules
  (`packages/orchestration/loop_spec.py`, `loop_run.py`, `apps/cli/commands/
  loop_cmd.py`, `queue_cmd.py` and the F048 queue modules), each with a deletion
  paragraph per amend0905-vocab D3 naming the heir: recurring order → order file +
  `remedy do <file>`; queued goal → `mission list --status planned`.
- `hidden` on `GroupDef`; the help renderer skips hidden groups in `--help` and
  `--all-commands`; dispatch still resolves them.
- The `job show --full` sections are the former commands' renderers, called in a
  fixed order; each former command's tests become section tests.
- The D11a test derives the group set from the catalog and refuses a `GroupDef`
  without `feature` and `reach` — F271 adds the fields; this feature lands the
  test in a form that F271 tightens (or F271 lands first if the order changes;
  the file that lands second cites the first).
- The doctor dead-command check (D11d) mirrors the F254 dead-model check: a
  catalog command whose handler is referenced by no test and no script is listed
  under `remedy doctor core` as a section, expected empty after this feature.
- Help wrapping: `_box` wraps the right column at the remaining width instead of
  truncating; a test renders a 200-character option help and asserts no `…`.
- The F259 test flip is one constant edit with the enforced-mode run green.
