# T9_F167 — SIEM / audit event export
**Tier 9 · Depends on: F009 audit, F059, F163 · Blocks/used by: enterprise integration; F172**

## Goal & Done
See ROADMAP.md F167; the Done criterion there is binding.

## Context (existing code & prior features)
commands_audit, decision events and job lifecycles exist scattered; one consumable stream is missing.

## Design
packages/enterprise/audit_export.py: a consolidated stream (sources: commands_audit, decisions, job lifecycle, worker.failover, lineage commits, policy violations) in two formats: JSONL (schema versioned via F245) and CEF lines. Sinks via [audit_export]: file (rotating), webhook (retry + spool on outage, NEVER blocking a run), syslog. The field schema ships as documentation for customer integrations.

## Task slicing
T001 collector + JSONL schema + file sink + tests. T002 CEF mapping + webhook/syslog + the outage spool + a SIEM-stub integration test.

## Acceptance & tests
A fixture run streams completely (reconciled against source logs); a sink outage loses nothing (spool test) and delays no job (latency assertion).

## Risks / anti-goals
The export is an append-only mirror, never a control channel; no prompt contents in the stream (anchors yes, texts no - the F174 line).
