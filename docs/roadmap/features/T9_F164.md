# T9_F164 — AI labeling in commits (standard)
**Tier 9 · Depends on: F139, F151 · Blocks/used by: F163 resolvability; audit expectations**

## Goal & Done
See ROADMAP.md F164; the Done criterion there is binding.

## Context (existing code & prior features)
F139 introduced the Remedy-Job trailer; model/worker are missing.

## Design
A binding trailer set in every Remedy commit: Remedy-Job:, Remedy-Task:, Remedy-Worker: <adapter>@<version>, Co-Authored-By: <model> via Remedy <version>. The gate lives in the ONE commit path (the worktrees commit helper - consolidating it is part of the task): a missing trailer is a programming error, hard test fail. `remedy audit commits [--since]` checks history and lists unlabeled foreign commits (informative).

## Task slicing
T001 commit-helper consolidation + trailer gate + tests. T002 the audit CLI + F139 switched to the same parser.

## Acceptance & tests
No Remedy commit without the full set (property over fixture runs); the squash-merge note in docs (trailer preservation) with a PR-description fallback test.

## Risks / anti-goals
Never relabel human commits; trailer names are frozen from now on (the F245 registry lists them).
