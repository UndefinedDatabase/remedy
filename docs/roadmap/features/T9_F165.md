# T9_F165 — Signed certificates
**Tier 9 · Depends on: F060, F012 · Blocks/used by: F156/F215/F238/F246/F247 signatures; M10**

## Goal & Done
Proof bundles gain cryptographic teeth: signing.py offers TWO
backends behind ONE interface — Sigstore/cosign keyless (OIDC
identity, transparency log) for connected setups, and a local
Ed25519 keypair (`remedy keys init`, public key exportable) for
air-gapped ones — signing the certificate's hash manifest as a
detached signature in the zip; `remedy verify <zip> [--pubkey |
--identity]` checks signature → manifest → files → lineage digest.
DONE when both backends sign and verify fixture bundles (with
tamper fixtures failing at the right layer and naming it), the
cosign path ships as an optional dependency with honest
degradation (unsigned certificates remain fully valid — signing
is additive trust, stated), key handling follows documented
custody rules (private keys never in evidence/exports — a
redaction-class guard), and the interface is the ONE signing home
later features import.

## How it fits (inspect current shape before building)
The certificate feature reserved the signature field and kept its
honesty line ("hashes are not signatures") — this feature fills
the reservation: the signed OBJECT is the existing hash manifest
(sign the root, inherit member integrity — no re-hashing
machinery); verify EXTENDS the existing chain (its current
manifest→files walk gains the signature layer in front and the
lineage-digest cross-check where present). Backend stance: Ed25519
via a small vetted crypto dependency IS required for the local
backend (stdlib has no Ed25519 — name the dependency choice in an
ADR; it is small, audited, and justified); cosign integrates as an
EXTERNAL TOOL (detected binary, an optional path — never a Python
base dependency), with the keyless flow's OIDC interaction being
interactive by nature (documented: keyless signing is an attended
operation; unattended pipelines use the local backend or a
provided key — honesty about ceremony).

## Design (suggested shape)
- `packages/enterprise/signing.py`: sign(manifest_path, backend)
  → detached signature file (+ certificate metadata for cosign:
  the transparency log entry ref); verify(bundle, {pubkey |
  identity constraints}) → the layered verdict {signature,
  manifest, files, lineage} with the first failing layer named.
- Backends: local (keys under <data_root>/keys/ with restrictive
  permissions, init/export/rotate commands — rotation keeps old
  public keys listed for verifying old bundles), cosign (binary
  detection, keyless sign/verify subprocess with identity
  constraint pass-through).
- Bundle layout: signature + metadata join the zip beside the
  manifest; the certificate JSON records signed: {backend,
  identity_hint | key_id, at} — display surfaces show the
  signed/unsigned state plainly.
- The custody guard: the redaction corpus gains private-key
  material patterns; key files excluded from every export/archive
  walker (a walk test).

## Task slicing
- **T001** the interface + the local backend (keygen, sign,
  verify, rotation, custody permissions) + tamper fixtures per
  layer + the dependency ADR.
- **T002** the cosign path (detection, sign/verify subprocess,
  identity constraints, attended-ceremony docs) + degradation +
  fixtures with a stubbed binary.
- **T003** verify-chain integration + bundle layout + display
  states + the custody walk/redaction tests + the end-to-end
  both backends.

## Acceptance
- Both backends round-trip; each tamper class fails naming its
  layer (signature vs manifest vs member vs lineage). Unsigned
  bundles verify their existing chain with the unsigned state
  displayed (never an error). Rotation verifies old bundles via
  listed keys. No key material in any export (walk + corpus).
  Cosign absent → the honest message, local path unaffected.

## Edge cases & assumption defaults (A9)
- Verifying on a machine without Remedy: the verify chain's
  independence goal — docs include the manual recipe (standard
  tools against the detached signature + manifest), tested in a
  bare-container fixture (the ten-year-readability spirit).
  Multiple signatures (org countersigning): out of v1, the
  format leaves room (a signatures list, documented).
