# T9_F165 — Signed certificates
**Tier 9 · Depends on: F060, F012 · Blocks/used by: F156/F215/F238/F246/F247 signatures; M10**

## Goal & Done
See ROADMAP.md F165; the Done criterion there is binding.

## Context (existing code & prior features)
certificate.zip + hash manifest + verify exist; cryptographic issuer binding is missing.

## Design
packages/enterprise/signing.py: two backends behind ONE interface - (a) Sigstore/cosign keyless (OIDC identity, transparency log) for connected setups, (b) a local Ed25519 keypair (`remedy keys init`, public key exportable) for air-gap (F173). Signed object: the hash manifest (detached signature in the zip). `remedy verify <zip> [--pubkey|--identity]` checks signature -> manifest -> files -> lineage digest (F163). The same backend later signs F215/F238/F246/F247 (one implementation).

## Task slicing
T001 backend interface + the Ed25519 path + verify extension + tests (valid/tampered/wrong key). T002 the Sigstore path + identity verify + docs for both modes.

## Acceptance & tests
Foreign-machine verify with only zip+pubkey passes; every tampering mode fails correctly; the air-gap path shows zero egress (capture test).

## Risks / anti-goals
No home-grown crypto (sigstore-python, pynacl only); key custody is the operator's duty - docs honest about that boundary.
