## Design
Command add_comment{target:{task|run|artifact, id}, body_md, anchor?}; storage jobs/<jid>/comments.jsonl (append-only; delete = an author tombstone). Rendering: sanitized markdown (the F041 sanitizer reused), anchors click into diff hunks/artifacts. UI: a comments tab in the EvidencePanel + a subtle counter badge on nodes (F126 restraint). A report appendix 'discussion' via --with-comments.

## Task slicing
T001 command + store + sanitizing + XSS corpus tests. T002 the UI tab + badges + anchor jumps + the report appendix.

## Acceptance & tests
A foreign comment is not editable/deletable (403 test); anchors resolve or degrade visibly ('target archived'); badge counts track via SSE.

## Risks / anti-goals
No rich-text editor project (a markdown textarea suffices); comments are context, never a control channel (nothing inside them is parsed as commands).
