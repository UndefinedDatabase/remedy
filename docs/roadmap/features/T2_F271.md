## Goal & Done
DECISION amend0905-vocab D11, verbatim:

(a) Every command group in the catalog names its owning feature and its reach
(golden-path, job-path, mission-path, self-use, teacher, cockpit, self-build); a
catalog test refuses a group without both. (b) A feature that replaces a mechanism
deletes the replaced mechanism in the SAME closure sequence — "replacing is
deleting" (added to AGENTS.md by amend0905-vocab-rebuild, Part 6). (c) An
import-reachability test asserts that no module outside an allowlist is importable
from the golden path (`do`), the job path, the mission path, the self-use runner,
the teacher and the cockpit read endpoints; a new orphan module reds the test. (d)
`remedy doctor` gets a dead-command check mirroring the dead-model check.

DONE when the Acceptance list holds.

## Why this exists
A prototype cluster — measured 2026-09-05 at 24 527 lines under
`packages/orchestration/` plus 4 731 lines of CLI handlers — sat unreached by the
build path for two months because nothing measured reach and no rule demanded
deletion on replacement. F260 deletes it; this feature makes sure the next one
cannot grow: ownership on every group, reach measured by a test, deletion demanded
by the closure protocol, dead commands reported by `doctor`.

## DECISIONs
D11 binds this feature. The AGENTS.md rule "Replacing is deleting" (Core Workflow,
directly after "No while I'm here edits", added by amend0905-vocab-rebuild) is cited,
not restated.

## Design
- (a) `GroupDef` gains `feature: str` and `reach: Literal["golden-path",
  "job-path", "mission-path", "self-use", "teacher", "cockpit", "self-build"]`;
  the catalog test (F261 lands its first form) refuses a group missing either.
- (b) The reachability test from F260 becomes closure precondition 7 in
  `docs/roadmap/STATUS_closure_protocol.md`: "no new module outside the reachable
  set unless its feature file names it".
- (c) `remedy doctor core` dead-command check: a catalog command whose handler is
  referenced by no test and no script is reported as a section, mirroring the F254
  dead-model check (`docs/system/model-defaults-and-dead-model-check-v0.md`).
  Expected empty after F261.
  Measured 2026-09-08 (brain run 006 Task 03, verified by the orchestrator and
  re-measured on this branch by an AST import pass over `packages`, `apps`,
  `scripts` and `tests`): nine modules under `packages/orchestration/` have exactly
  one Python importer and it is a test file, and none of them appears in
  `tests/orchestration/import_reachability_allowlist.txt` — `builder_eval.py` (829
  lines, additionally invoked by `scripts/remedy_builder_eval.sh`),
  `feature_mission_adapter.py` (461), `patch_revert.py` (290, imported by
  `tests/orchestration/test_source_apply.py`, not by a test named after it),
  `diagnostic_comparison.py` (172), `ci_budgets.py` (86), `bench_run.py` (84),
  `task_plan_evidence.py` (72), `execution_config_evidence.py` (64) and
  `self_use_findings.py` (55) — 2 113 lines that are green, count toward coverage and
  serve no product path. The reachability test asserts that nothing outside the
  allowlist is REACHABLE; it does NOT assert that every module IS reachable. This
  feature adds the mirror: `tests/test_no_orphan_modules.py` (beside
  `tests/test_imports.py`, listed in `ARCHITECTURE_FILES` in `tests/conftest.py`), an
  AST pass over `packages` + `apps` + `scripts` that fails on any module with zero
  non-test importers, excluding `__init__.py`, the documented reserved namespaces and
  an `ALLOWED_UNWIRED` tuple with a one-line reason per entry; registered in the
  `budgets` CI stage. The nine are resolved cheapest first — wired to a real entry
  point, or deleted with their test and the deletion recorded. `builder_eval.py` needs
  a dated DECISION before either.
- (d) The AGENTS.md rule is cited in the closure protocol beside precondition 7.

  AGENTS.md rule.
