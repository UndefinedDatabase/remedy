# T1_F033 — Hunk-genaue Diff-Freigabe
**Tier 1 · Abh.: F031, F037**

## Ziel & Done
Approval-pflichtige Änderungen pro Hunk annehmen/ablehnen; Abgelehntes → präzises
Repair-Feedback. Done: Teilfreigabe → korrekter Patch + Repair-Runde für Rest.

## Design
- Diff-Splitting: unidiff-Parser (`packages/orchestration/hunks.py`), Hunk-IDs stabil
  (file+context-hash); Command `approve_hunks{decision_id, approved:[hid], rejected:
  [{hid,reason}]}`.
- Wirkung: approved-Hunks → Patch anwenden (git apply im Worktree); rejected →
  Repair-Prompt-Baustein (F111-Format) mit Hunk+Grund.
- UI: DiffViewer (F037) mit Checkbox je Hunk + Grund-Feld bei Ablehnung.

## Task-Schnitt
- T001: hunks.py+apply-Pfad+Tests (Mischfreigabe-Fixture).
- T002: Command+Repair-Baustein; T003: UI-Checkboxen.
