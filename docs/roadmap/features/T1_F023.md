# T1_F023 — Semantischer Zoom L0–L3
**Tier 1 · Abh.: F019, F020 · Blockiert: F037/F038-Einstieg · Referenz: H3/H4**

## Ziel & Done
Vier Stufen, Zoom==Klick, Brotkrumen, Esc, Cluster >8, 60 fps bei 500 Nodes in L0.

## Design
`useSemanticZoom.ts` — eine Zustandsmaschine, keine zwei Navigationslogiken:
```ts
type ZoomState={level:0|1|2|3; focusTask?:string; focusRun?:string; focusArtifact?:string}
// Übergänge: click(task)->L1(task) | click(run)->L2 | click(synapse|artifact)->L3
// wheelZoom: kontinuierlicher k-Wert; Schwellen k<1.4→L0, 1.4–2.6→L1(nächster Task
// zum Viewport-Zentrum), >2.6 behält L1, L2/L3 NUR per Klick (Popover/Panel sind
// keine Zoomflächen). Esc: L3->L2->L1->L0. Doppelklick Leere -> L0 + zoomToFit(600ms)
```
- Sichtbarkeits-Selektor `visibleGraph(state)`: L0 = job_core+tasks (+cluster der Runs
  als Ast-Glow, F020); L1 = zusätzlich Kinder des focusTask, Geschwister-Tasks alpha .25;
  Cluster-Node ab >8 Kinder eines kinds, Klick expandiert (state.expandedClusters:Set).
- L2: `NodeDetailPopover` (existiert) erweitert: Verdict-Badge, Tokens/Kosten (F003),
  Dauer, Retries (F001), Buttons „Diff" (F037) „Warum?" (F038) „Rerun" (F029, bis dahin
  disabled+Tooltip). Synapsen des Runs werden auf seiner Kante eingeblendet.
- L3: `EvidencePanel` (Seitenpanel, 420 px, schiebt Graph nicht — overlay rechts,
  unter der Rail): Tabs Diff | Prompt-Trace | Chat(F038).
- Brotkrumen oben links im Stage: `Job › implement_directory_scanner › Builder-Run 2`
  (Klick auf Segment = Stufe zurück).
