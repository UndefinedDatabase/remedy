## Goal & Done
The reference's design language becomes enforceable code: the
spec's token candidates generate a tokens.css in the TARGET
project's own namespace, a stylelint rule forbids raw hex outside
tokens.css, and builder prompts mandate token variables — with the
reference remaining the source of truth on any conflict. DONE when
fixture specs generate clean token files (deduplicated,
role-named, namespaced per project), the lint rule catches seeded
raw-hex violations in CI/DoD, builder prompts on design jobs carry
the mandate (trace-proven), and regeneration reconciles instead of
clobbering hand-curated names.

## How it fits (inspect current shape before building)
Candidates arrive per reference from decomposition — extraction
RECONCILES across references (same hex within a delta → one token;
role hints vote on naming) into the target project's stylesheet
conventions (detect the project's CSS entry structure; the token
file lands where the project's styles live, wired via a normal
task/diff — Remedy edits the target through the applicator like
any change, fences applying). The namespace derives from the
project slug (--<slug>-*), NEVER --remedy-* (that namespace is
Remedy's own cockpit — the collision would be absurd and the
guard test says so). The lint rule ships as a DoD check (kind
lint with the stylelint config generated/extended in the target).

## Design (suggested shape)
- Reconciliation: candidates → clusters (color delta threshold,
  radius/shadow equality) → tokens {name (role-vote + ordinal
  fallback: --slug-blue-600 style), value, sources: [R-refs]} —
  deterministic given the spec set (goldens).
- Generation: tokens.css with a generated-region marker (the ADR
  cards' fenced-region pattern reused) — human renames/additions
  below the marker survive regeneration; renames map old→new in a
  companion record so regeneration keeps human names for stable
  values.
- The lint: a stylelint configuration enforcing no raw hex/px
  radii outside tokens.css (rule set documented; the target's
  existing lint setup extended, not replaced — A6 in the target's
  world too); wired as a DoD lint check on design jobs.
- Prompt mandate: the builder style block (F088's segment) gains
  the token table + the "use variables, never raw hex" line —
  trace-proven; violations then fail the lint check (belt and
  suspenders).
- Conflict rule: reference wins — a hand-edited token VALUE
  drifting from the reference is flagged by the fidelity loop's
  colors criterion naturally; the docstring states the hierarchy.

## Edge cases & assumption defaults (A9)
- Targets without stylelint: the DoD check installs a minimal
  config as part of the design job's diff (a reviewed change,
  fenced) or reports tool_unavailable honestly if the ecosystem
  doesn't fit (non-CSS stacks: the extraction still generates the
  token FILE; enforcement degrades with the note). Gradients/
  images: out of v1 scope, listed in the record as unextracted.
