## Goal & Done
The self-use generator's Tier 2 and Tier 3 are built, so that a closure's self-use run has real
work when the finding ledger is empty. Tier 2 is a documentation-staleness catalog: concrete
checks of the form document, claim and shipped truth, at least ten real checks over the README,
the guides and the command catalog. Tier 3 is `remedy doctor core` refactored into an importable
function that returns structured warnings, with each actionable warning rendered as a one-task
job. DONE when three consecutive generator calls on an empty ledger each produce a distinct item
that a run can finish inside the default cost cap.

## Why this exists
Today `_doc_staleness_tier` and `_doctor_warning_tier` in
`packages/orchestration/self_use_generator.py` return nothing (DECISION F258 D2), so the only
sources are the finding ledger and the operator's standing order. When both are empty, a closure's
self-use run has nothing to do, which is how F027's closure ended with "queue exhausted". The
self-use track exists to show Remedy repairing itself, and it needs work to repair.

## Task slicing
- T001 — Tier 2: the staleness catalog with at least ten checks, each naming the document, the
  claim and the shipped truth it compares, and the generator rendering one failing check as a
  one-task job.
- T002 — Tier 3: `doctor core` as an importable function returning structured warnings, the
  command line printing from it unchanged, and the generator rendering one actionable warning as a
  one-task job.
- T003 — the proof: three consecutive generator calls on an empty ledger produce three distinct
  items, and one of them runs to completion under the test provider inside the default cost cap.

## Acceptance
- The staleness catalog holds at least ten checks over the README, the guides and the command
  catalog, and each is proven red on a stale fixture.
- `doctor core`'s warnings are importable as data, and its command-line output is unchanged.
- Three consecutive generator calls on an empty ledger each produce a distinct item.

## Do not touch
Tier 1 (the finding ledger) and the standing order's precedence; the fence over `.agent/` that a
self-use run carries (DECISION amend0926-decisions-selfuse D4).
