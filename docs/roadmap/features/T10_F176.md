# T10_F176 — SSO/OIDC for the cockpit
**Tier 10 · Depends on: F175, F009 CSRF · Blocks/used by: F177, F201 remote**

## Goal & Done
See ROADMAP.md F176; the Done criterion there is binding.

## Context (existing code & prior features)
ui_server uses static bearer + CSRF; the stdlib-server principle should hold.

## Design
OIDC authorization code + PKCE without a framework: packages/org/oidc.py (discovery, token exchange via urllib, JWT verify with jwks - pyjwt allowed); an HttpOnly SameSite=Strict session cookie -> a server-side session map {sid -> user_id, exp}; command paths read the user from the session. A claims mapping [oidc] role_claim -> F175 roles. The local fallback (users.toml tokens) stays fully supported; the mode is config.

## Task slicing
T001 oidc.py + the session layer + tests against a dex fixture (CI container, subprocess marker). T002 role claim mapping + fallback coexistence + one full UI E2E pass in session mode.

## Acceptance & tests
The login flow passes against the test IdP; an expired session re-logins cleanly without losing inbox form state; CSRF protection stays intact (existing tests).

## Risks / anti-goals
No OAuth rebuild of the API (the CLI stays token-based); no roles from unverified claims.
