# T15_F226 — Classic risk prediction
**Tier 15 · Depends on: F103, F139, F074, F133 · Blocks/used by: the F223 trigger; F131 depth steering; flight-plan notes**

## Goal & Done
See ROADMAP.md F226; the Done criterion there is binding.

## Context (existing code & prior features)
The ledger holds rich history after 150 features (class, module, worker, repair rounds, fails); F074 calibrates costs only.

## Design
packages/intel/risk_model.py: a small explainable model (start: logistic regression; GBDT only if the backtest justifies it - ADR) over ledger features {task class, module-path churn (F139), worker trust (F133), the module's historical repair quota, diff size band}; targets P(repair>1) and P(fail). Training is offline (`remedy intel train`, seeded); the model file is versioned + a model card (data period, n, metrics, feature weights). Uses: a flight-plan risk note ('statistical: elevated repair risk, n=..'), the F131 trigger, the F223 trigger. NEVER blocking on its own.

## Task slicing
T001 feature extraction + training + a backtest harness (a TEMPORAL split!) + tests. T002 the model card + the usage sites (note/F131/F223) + a minimum-n rule (below it the model is inactive and honestly shown as such).

## Acceptance & tests
The backtest beats the base rate with a documented metric (AUC/Brier in the model-card golden); weights are inspectable; below minimum n everything behaves as without the feature.

## Risks / anti-goals
No online learning (training is a deliberate act); every score explains itself (top-3 factors per prediction in the note); never person features.
