# T2_F077 — Autonomy watchdog
**Tier 2 · Depends on: F070, F010, F018 · Blocks/used by: safety in continuous operation**

## Goal & Done
See ROADMAP.md F077; the Done criterion there is binding.

## Context (existing code & prior features)
Loops, burn anomalies and goal drift need a tripwire.

## Design
watchdog.py monitors the orchestrator loop: same task 3x without progress, burn-rate anomaly (own sliding-window check; later unified with the F116 detector), jobs without milestone linkage; reaction: pause the mission + a decision with the evidence triple. The watchdog stops; it never repairs.

## Task slicing
T001 detectors + per-pattern tests. T002 pause+decision path.

## Acceptance & tests
A simulated always-fail loop pauses after 3 with a clean decision.

## Risks / anti-goals
Repair after a watchdog stop is a human/orchestrator decision.
