## Goal & Done
See ROADMAP.md F116; the Done criterion there is binding.

## Context (existing code & prior features)
A runaway loop could burn budget fast between checkpoints.

## Design
Burn-rate detector: sliding usd/h per job vs. class expectation; outliers (>3x P80) warn via SSE+notify and can throttle parallelism or raise a pause decision on unattended runs.

## Task slicing
T001 detector + thresholds + simulated-outlier test. T002 throttle/pause path.

## Acceptance & tests
Simulated outlier warns <60 s; throttling documented; no auto-stop below the hard 5x threshold (proportionality).

## Risks / anti-goals
Warn and throttle first; stopping is a decision.
