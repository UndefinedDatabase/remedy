## Goal & Done
The full suite costs at least 40 percent less CPU time than F293's T001 baseline, 1,246.09 CPU
seconds, without losing a single assertion. DONE when the full suite's CPU seconds, read from the
test load record, are at most 747.65, OR the ranking shows that what remains cannot be made cheaper
without weakening a test, and a dated DECISION says so with the numbers.

## Where it starts
F293's closure suite (`.agent/authored/f293-closure-suite.txt`, round 21) used 940.64 CPU seconds
for 21,145 collected tests, 24.5 percent below the baseline, so about 193 CPU seconds are still to
cut. DECISION F293 D10 names the largest cost the end-to-end tests still carry: one `remedy do` run
of a one-task job on the fake providers used 2.19 CPU seconds, about half of it in the 210 git
processes the job runner starts (three readings of `worktree_identity`, 31 calls of `write_tree_at`
and 15 of `capture_target_state`). Fewer git processes per job run would speed up every real job
as well as the tests; that is product work in the job runner, which F293 left out as beyond a test
diet. The files that run whole jobs through the command line, `tests/cli/test_do_sequence_cli.py`,
`tests/cli/test_golden_path.py` and `tests/cli/test_do_commit_flags.py`, are the first to measure.

## Built State (F294, 2026-10-01)

What exists on disk before the closure sequence of F294, built on `feature/f294-test-load-diet-two`,
cut from `main` at `020bc9a16`. Every DECISION named lives in `.agent/decisions.md`; every round's
verdict in `.agent/live_review.md` or, once rotated, its archive.

**T002 — the cuts.** Each was measured before and after in one tree, and each kept its red-proof. A
reading of a repository's identity discovers the configured helpers once instead of before each of
its six git commands (DECISION F294 D1), and runs `git submodule status`, a shell script on the
operator's git, only when the index holds a submodule (D3); both make every job run start less
work, in the tests and for the operator. Every test's data root comes from one parent per test
process, so no test lists the whole base temporary directory to number its root (D2). The
golden-path tests run `init`, `do` and `status` in the test process, and the scoped-listing tests
their setup, through `tests/cli/in_process_cli.py`, while every other command those files assert on
still runs as a child process (D4, D5). No test body changed for these cuts and no assertion was
removed.

**What remains.** DECISION F294 D6 records every file reading this feature took and one job run's
profile. The costliest files left run a real job in every test and then change what it left, so
their cost is the job run itself, and what a job run still costs is product work: absorbing a human
change at every safe point, and the definition-of-done gate running the target's tests. The
closure's one full suite gives the "after" reading of the 40 percent target.
