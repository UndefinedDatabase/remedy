## Goal & Done
"How close is it?" becomes a number with a picture: compare(ref,
shot) computes SSIM, pixel-diff percentage and per-region scores
(the decomposition's bboxes) plus a heatmap PNG that localizes
deviation — deterministic, dimension-honest, dependency-lean. DONE
when the metric suite reproduces goldens on a constructed fixture
set (identical, shifted, recolored, region-local changes), region
scores localize the seeded deviations to the right boxes, dimension
mismatches are handled by a documented rule instead of silent
resizing, and the metrics ship inside the same optional design
extra as capture.

## How it fits (a dependency note, consistent with the tier)
The imaging stack (SSIM etc.) lives in the `remedy[design]` extra
alongside the browser — never base (the F090 stance; one extra for
the tier). Inputs are evidence files (the reference from the
addressing table, the shot from captures/); output is a comparison
record (versioned JSON) + heatmap into the job's comparisons/ area
— pure functions over pixels, no LLM, no network (the visual
REVIEWER is the next feature; this one only measures — keep the
boundary sharp: numbers here, judgments there).

## Design (suggested shape)
- compare(ref_path, shot_path, regions?) → {overall: {ssim,
  pixel_diff_pct}, region_scores: [{name, bbox, ssim,
  pixel_diff_pct}], heatmap_path, dims: {ref, shot, rule_applied}}.
- Dimension rule (documented, tested): equal dims → direct; equal
  aspect ratio → scale the shot to the ref with the note; different
  aspect → compare the overlapping top-left crop AND flag
  aspect_mismatch prominently (a wrong-viewport capture is a
  finding, not something to blur away).
- Heatmap: per-pixel difference intensity rendered with a
  documented colormap; region boxes drawn on it (the decomposition
  overlay's drawing pass reused) — the reviewer and the human read
  the same picture.
- Determinism: identical inputs → identical outputs bit-for-bit
  (no randomness anywhere; goldens enforce).
- Tolerance vocabulary: this feature reports raw numbers; the
  LOOP feature owns thresholds (SSIM ≥ target) — no pass/fail
  here (measurement/judgment separation again).

## Task slicing
- **T001** metrics + dimension rule + unit goldens on the
  constructed set (synthetic images with known SSIM behavior:
  identical=1.0, seeded noise bands, shifted copies).
- **T002** region scoring on decomposition bboxes + localization
  goldens (deviation seeded in region B → B's score drops, A's
  holds).
- **T003** heatmap + boxes + the comparison record/evidence + the
  end-to-end (capture a fixture, compare against its doctored
  reference; artifacts complete and deterministic across two
  runs).

## Acceptance
- Golden numbers exact; bit-identical reruns. Localization
  fixtures land in the right regions. Dimension matrix (equal,
  scaled, aspect-mismatch) per rule with flags. No thresholds, no
  verdicts in this module (grep). Extra-gated import (base
  install untouched).

## Edge cases & assumption defaults (A9)
- Transparency/alpha: composited onto the reference's background
  assumption (white default, config) — documented. Huge images:
  processed at capture resolution; comparisons never upscale the
  reference (the reference is the truth's resolution).

## Orchestrator brief

metrics work without them; say so). The measurement/judgment

synthetic set makes SSIM behavior reviewable; enumerate it.
