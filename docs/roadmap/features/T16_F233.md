## Context (existing code & prior features)

## Design
A precondition GATE: this feature STARTS with the F044 measurement series; if stage 1 holds the budget, the feature ends as a documented NON-implementation (an ADR: 'stage 2 not needed; numbers attached') - that is a valid Done. Otherwise: apps/ui/src/components/brain/renderers/ with a RendererPort interface (mount, setGraph, setVisible, applyZoom, drawNode delegating to glyphPaths.ts - ONE glyph source remains); a PixiRenderer (WebGPU, automatic WebGL fallback); the d3-force layout stays in a worker thread (layout and rendering separated); particles as a ParticleContainer; glow via filters under a budget (max n concurrently). A feature flag [ui] renderer=auto|fg2d|pixi with a runtime fallback on WebGL init failure. Snapshot parity: the F020 matrix (8 kinds x 7 states) against stage-1 goldens within tolerance.

## Task slicing
T001 the F044 measurement series + the gate ADR. T002 RendererPort + an fg2d adapter (a behavior-preserving refactor, golden-guarded). T003 the PixiRenderer + parity snapshots + a 2000-node perf fixture. A LARGE block (A3).

## Acceptance & tests

## Risks / anti-goals
