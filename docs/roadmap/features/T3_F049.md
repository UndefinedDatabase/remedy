# T3_F049 — Parallelism
**Tier 3 · Depends on: F006, F048, F057 · Blocks/used by: wall-time KPI**

## Goal & Done
See ROADMAP.md F049; the Done criterion there is binding.

## Context (existing code & prior features)
One task at a time wastes wall time on disjoint work.

## Design
parallel_scheduler: up to N workers (config max_parallel), each in its own worktree, one thread-safe budget guard; rate signals throttle dynamically; ONLY path-disjoint tasks run in parallel (allowed_paths intersection empty).

## Task slicing
T001 scheduler + disjointness + budget thread-safety + tests. T002 3-task integration run with wall-time measurement.

## Acceptance & tests
Measurably shorter wall time; zero worktree/path collisions.

## Risks / anti-goals
Never parallelize beyond path disjointness (deliberately conservative).
