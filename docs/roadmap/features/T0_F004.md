## Goal & Done
See ROADMAP.md F004; the Done criterion there is binding.

## Context (existing code & prior features)
agent_run_trace.py reconstructs tool sequences from prompts today; per-task evidence folders exist.

## Design
`stream_evidence.py`: subprocess wrapper tees stream-json stdout to task_runs/Txxx/raw_stream.jsonl AND parses inline to normalized run_events.jsonl (tool_use with input digests, api_retry, token deltas, result) in the SSE envelope shape. Rotating size cap 50MB/task; redaction filters run BEFORE the tee. Opt-in via --stream-evidence (default stays JSON, F003).

## Task slicing
T001 wrapper + parser + recorded-stream fixtures. T002 provider flag + agent_run_trace consumes run_events. T003 live smoke on a mini task; old/new trace comparison.

## Acceptance & tests
Every run_event carries a raw-offset backreference; api_retry events visible; token deltas roughly sum to F003 actuals; canary secrets never reach raw_stream (redaction corpus).

## Risks / anti-goals
Opt-in only (verbose output costs tokens). No secrets in raw streams, ever.
