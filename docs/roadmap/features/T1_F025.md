# T1_F025 — Pause/Resume (global & pro Node)
**Tier 1 · Abh.: F009, F011, F003(session_id)**

## Ziel & Done
Pause stoppt vor nächstem Provider-Call; Resume exakt fort. Done: Pause→Resume-Lauf ==
ununterbrochener Lauf.

## Design
- Commands: `pause_job{}, resume_job{}, pause_task{task_id}, resume_task{task_id}`.
- Mechanik: Pause-Flags in job_state; Checkpunkte identisch F011; laufender Provider-Call
  läuft zu Ende (kein Kill), danach Halt. Resume nutzt session_id (F106-Vorgriff nur
  Persistenz, kein --resume nötig da zwischen Calls pausiert wird).
- UI: Pause-Button in Rail-Kopf; Node-Kontextmenü (L1) „Task pausieren"; Zustand
  `paused` als Node-State-Overlay (Pausenbalken-Glyphe, --rm-ink-2).

## Task-Schnitt
- T001: Flags+Checkpunkte+Commands+Tests (Vergleichslauf Fake-Provider).
- T002: UI-Buttons+Kontextmenü+SSE-Status.

## Akzeptanz & Tests
- Ergebnis-Hash Pause/Resume == Durchlauf (F012-Determinismus, Fake-Provider).
