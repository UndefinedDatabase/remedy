# T1_F015 — Interaktives Plan-Editing
**Tier 1 · Abh.: F014, F009 · Blockiert: F026-Muster**

## Ziel & Done
Tasks im Flight Plan löschen/ändern/umsortieren/mergen/splitten; Akzeptanzkriterien
editierbar. Done: editierter Plan wird exakt so ausgeführt (user_edited_plan-Evidence).

## Design
- Commands (Katalog-Erweiterung): `plan_edit_task, plan_delete_task, plan_reorder,
  plan_merge, plan_split` — wirken NUR vor approve_plan; danach 409.
- flight_plan.py: Edit-Log `plan_edits.jsonl` (wer/was/wann), Hash-Neuberechnung,
  DAG-Revalidierung (Zyklen, verwaiste depends_on → Fehlermeldung im UI).
- UI: Inline-Edit in FlightPlan.tsx (Titel/Intent/Kriterien contenteditable-Feld,
  Drag-Reorder via HTML5 DnD, Merge per Mehrfachauswahl).

## Task-Schnitt
- T001: Backend-Edits + Validierung + Tests (Zyklus-Erkennung).
- T002: UI-Editing + optimistic update + SSE-Sync.

## Akzeptanz & Tests
- Property-Test: beliebige Edit-Sequenz → Plan bleibt valider DAG oder klare Fehlermeldung.

## Risiken / Anti-Ziele
- Kein Editieren nach Start (das ist F026 mit anderem Pfad + Evidence).
