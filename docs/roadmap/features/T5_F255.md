## Goal & Done
A fourth configured role that narrates a running mission and tutors the
operator on their own project's real code, without ever influencing the
run. DONE when the scope below is built and accepted: passive narration
(Stage 1) plus on-demand Q&A (Stage 2), separate budget pool, read-only
invariants enforced.

## Scope (registered verbatim, plan0806 2026-08-06)
A fourth configured ROLE named teacher, resolved through the same
role_config mechanism as orchestrator/worker/reviewer (harness or
local model per role). It explains a running mission as it happens —
what is happening AND why — and answers operator questions at any
time, cheaply. Operator motivation (2026-08-06): waiting on an agent
is dead time; this role turns it into learning and live context
awareness, and doubles as a learning platform (students included):
an operator building a project in an unfamiliar language (e.g. a
Swift game) learns that language alongside the build, on their own
project's real code, plus Remedy's own concepts. THREE grounding
sources, each with its own honesty rule: (1) ledger/evidence — what
is happening; asserts only what evidence shows, says unknown where
it is silent; (2) workspace code, read-only — what this function/file
does; explains code that exists, never invents; (3) the teacher
model's language/concept knowledge — what a term means; normal tutor
knowledge, clearly not a claim about Remedy state. Never mixes
sources silently. Interaction: passive narration keyed to ledger
events (Stage 1: deterministic templates, zero tokens, offline) plus
on-demand Q&A (Stage 2: LLM via the teacher role's own model, small
context = relevant ledger slice + the asked-about code location,
cache-stable prefix). Cost: teacher spend is its OWN budget pool,
reported separately from mission spend in the F103 ledger. Style
rules in the teacher system prompt: no complicated words, human and
plain; a level dial (student / beginner / pro) adjusts depth of the
same explanation. Hard invariants: ActionClass read_only; may never
influence the run; same isolation rules as watch. CLI-first:
`remedy do watch --learn` and `remedy teach ask "<question>"`;
cockpit panel lands with Tier 5. Dependencies: stable ledger event
vocabulary (Tier 2), F103 for budget separation.

## Non-goals
Any write access to the run, mission steering, or influence on
orchestrator/worker/reviewer decisions; cockpit panel ships with
Tier 5, not before.
