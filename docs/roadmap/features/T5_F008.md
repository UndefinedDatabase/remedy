## Goal & Done
See ROADMAP.md F008; the Done criterion there is binding.

## Context (existing code & prior features)
ui_server serves REST; SQLite event cursors + run_events exist as sources.

## Design
GET /api/jobs/{jid}/events/stream: SSE from the event cursor, monotonic seq, 15 s heartbeat, Last-Event-ID resume; envelope per Part E. Client hook useBrainStream (EventSource, reconnect+backoff, gap detection -> snapshot refetch); polling fallback with an honest 'delayed' badge.

## Task slicing
T001 endpoint + resume + threading tests (stdlib server: one worker thread per stream). T002 client hook + fallback + gap test.

## Acceptance & tests
Event -> UI <1 s; reconnect after a killed connection loses nothing (seq check).

## Risks / anti-goals
No websockets; no third transport.
