## Goal & Done
A task that the run splits (T001 becomes T001a and T001b) leaves the job's run manifest written and
valid. DONE when a job whose one task is split during the run ends with a run manifest; the
manifest records the split as Remedy's own change, with the parent's id, the parts' ids, the round
and the reason; the F7 check in `packages/orchestration/run_manifest.py` accepts a task list whose
split parts stand in their parent's place and still refuses an edit of the list from outside; and
every strict decoder, the external schema and every validator that names the declared task list
accept the recorded split.

## Why this exists
Finding R-1252 was raised at F297's closure from the self-use run SU-056, job
`7119e375144244c2`. A run with `max_tasks` 1 split its one task; T001a passed review and T001b
waited, and the job carried `run_manifest_error: run_manifest_write_failed: … the job's task list
['T001', 'T001a', 'T001b'] no longer matches the episode-start snapshot's job-input definition
['T001']`. A split is Remedy's own change to the task list, not an edit from outside, so today the
episode's record of what ran is lost on every split. DECISION F306 D2 found the repair too large
for a paydown round.

## Task slicing
- T001 — The split record. Where the run performs the split, it writes the split map into the
  run's record (the parent, the parts, the round and the reason), and the manifest writer reads it.
- T002 — The F7 check and the decoders. A task list that equals the snapshot's list with each
  split parent replaced by its parts, in order, is accepted; any other difference is still
  refused; the external schema and the strict decoders carry the split map.
- T003 — The proof. A test starts a job of one task, splits the task during the run through the
  real split path, and expects a written, valid run manifest that names the split; a test shows
  that an edit of the task list from outside is still refused; and the self-use runner's
  `run_defects.txt` names a split job's manifest as present.

## Acceptance
The three tests above are green; `tests/orchestration/test_run_manifest_integrity.py` stays green
unchanged; R-1252 carries a resolution line that names this feature's evidence.

## Do not touch
The manifest's hash chain, and the F7 refusal of an edit from outside.
