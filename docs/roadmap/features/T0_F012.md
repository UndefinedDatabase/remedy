# T0_F012 — Deterministic runs
**Tier 0 · Depends on: F004 · Blocks/used by: F084, F140, all golden tests**

## Goal & Done
See ROADMAP.md F012; the Done criterion there is binding.

## Context (existing code & prior features)
Evidence writers call datetime.now directly; fake provider is unseeded; runs are not reproducible.

## Design
`determinism.py`: pinned env (TZ=UTC, LANG=C.UTF-8, PYTHONHASHSEED), injectable Clock protocol in all evidence writers, project-relative path normalization, bare-mode CLI flags where supported (sniffed with fallback). determinism.json per run (env digest, clock mode, flags). Seeded fake provider; golden runs become fixtures.

## Task slicing
T001 module + clock injection across writers (deliberately LARGE task, A3 - touches many files). T002 fake-provider seeds + double-run hash comparison.

## Acceptance & tests
pytest -m determinism: double run bit-identical (hash manifest); real runs write determinism.json.

## Risks / anti-goals
Never claim full determinism for real LLM runs (P6) - only the environment is fixed, and the report says so.
