## Goal & Done
Every event the UI server sends for a builder attempt, a review, a check, a test run and a repair
round carries the attempt id, the task id and the result; a plan-approved event exists; and prompts
become their own node kind in the live graph, so the prompt dots leave the simple view. Every
consumer of the stream is updated in the same feature. DONE when the live graph shows a node for
every kind the simple view shows, and the reducer's tests prove that test-run and repair nodes
appear.

## Why this exists
F019 built the live graph from the event messages as they are, because its plan forbade changing
the message format (operator question Q2). As a result the tasks appear only when the task list
appears, test runs and repair rounds have no nodes, and the prompt dots stay in the simple view
because the graph's data model has no prompt node (operator question Q3). The operator accepted
both as interim states and asked for the missing fields and the prompt nodes as their own feature.

## Task slicing
- T001 — the event fields: attempt id, task id and result on every builder, review, check, test and
  repair event, and a new plan-approved event, with every reader of the event vocabulary updated
  (the UI contracts, the humanized labels, the command line and the tests).
- T002 — the live graph reducer: test-run and repair nodes, and tasks appearing at plan approval,
  proven by the reducer's tests.
- T003 — prompt nodes: a prompt node kind in the graph's data model and its look, so the prompt
  dots are reachable in the live picture with the mouse and the keyboard.

## Acceptance
- Every builder, review, check, test and repair event carries the attempt id, the task id and the
  result, and a plan-approved event is sent when a plan is approved.
- The reducer's tests show test-run and repair nodes appearing from the stream.
- The live graph shows a node for every kind the simple view shows, prompts included.

## Do not touch
The simple view, which stays one click away; the graph's rule that it never draws a node its data
model does not hold.
