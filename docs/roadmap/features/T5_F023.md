## Goal & Done
One mental model from organism to evidence: a zoom state machine
{level, focusId} drives L0 (job core + task ring, runs as branch
glow) → L1 (focus task expanded, siblings 25% dim) → L2 (run
popover: verdict, tokens, duration, retries, diff/why/rerun
buttons) → L3 (EvidencePanel side panel: tabs diff | prompt trace
| chat) — with wheel thresholds, click equivalence, breadcrumbs,
Esc walkback and cluster expansion, at the stage-1 perf budget.
DONE when every transition path (wheel, click, breadcrumb, Esc)
lands the goldened state, the L2 buttons wire to their real
backends or render the honest not-yet pattern, clusters expand
per rule, and 60 fps holds at 500 nodes on the perf fixture.

## How it fits (binding interaction spec, restated)
useSemanticZoom state machine {level, focusId}. Wheel thresholds
with hysteresis (zoom-in on a node >1.6, out <0.8), click = the
same transitions, breadcrumbs Job > Task > Run, Esc walks back,
clusters above 8 children ('+12' expands). Perf budget: 60 fps at
500 nodes (stage-1 scope). EvidencePanel CSS core:
```css
.evidence-panel{position:fixed;right:0;top:0;bottom:0;width:min(560px,44vw);
  background:var(--remedy-bg-2);border-left:1px solid var(--remedy-line);box-shadow:-18px 0 40px rgba(37,50,79,.08);
  display:flex;flex-direction:column;animation:slideIn .22s ease}
```
Level semantics render on the reducer's model (F019) with the
glyph language (F020); L2/L3 CONTENT comes from evidence
endpoints (run verdicts, token actuals, diffs, prompt traces —
all existing artifacts served read-only; inventory the endpoints,
add thin read routes where missing as named prerequisite orders).

## Design (suggested shape around the binding spec)
- The state machine as a pure store module (transitions
  goldenable headless): enter(level, focusId) validated against
  the model (focusing a nonexistent node is a no-op with a debug
  note); hysteresis lives in the wheel adapter, not the machine.
- L1 dimming/expansion and L0 branch-glow are render-layer
  effects driven by {level, focusId} — no model mutation.
- L2 popover: anchored per reference; buttons — diff → L3 diff
  tab; why → L3 prompt trace scrolled to the verdict; rerun →
  the write channel's command IF exposed, else the disabled+
  tooltip pattern (check the channel's exposed list — growth is
  per-feature).
- L3 EvidencePanel: tabs lazy-load their endpoint; chat tab is
  the not-yet pattern until its feature. Deep-linkable state
  (?focus=&level=) for the timeline and feed jumps.
- Cluster expansion: '+N' nodes expand into their children at
  L1 focus per graph_spec's rule; collapse on unfocus.

  both sides. L2 data matches evidence fixtures; every button
  either works or honestly says when it will. Deep links restore
  state. Perf fixture ≥60 fps stage-1 (recorded; failing it opens
  the stage-2 conversation per the F019 decision, no silent
  degrade).

## Edge cases & assumption defaults (A9)
- Focus on a node that clusters away mid-stream: focus follows
  into the cluster's expansion or walks up one level with a note
  (never a dangling focus). Keyboard: Esc chain is binding; full
  keyboard nav is the a11y feature's scope later — the machine's
  API doesn't preclude it.

## Built State (F023, 2026-09-25)

What exists on disk at the close of F023, built in seven rounds in one session on
`feature/f023-semantic-zoom-l0-l3`, cut from `main` at `441f4e8e`. Every DECISION named lives in
`.agent/decisions.md`; every round's verdict in `.agent/live_review.md` or, once rotated, its
archive.

**T001 — the state machine and its goldens.** `apps/ui/src/components/graph/semanticZoom.ts` is the
pure machine {level, focusId, tab}: click, wheel in, wheel out, Escape, breadcrumb, open evidence
and reconcile, each a function of the graph, the state and the event; a refused or empty transition
hands back the same state, with a debug note where the refusal names a cause, and focus is checked
against the reducer's model together with its clustered view, so a run a cluster hides can still be
focused and a focus never dangles. `zoomWheel.ts` holds the hysteresis: an event fires only when the
camera factor crosses strictly above 1.6 over a node or strictly below 0.8, the numbers
`graph_spec.md` §10 states (DECISION F023 D1).

**T002 — the render effects, the breadcrumbs and the L2 run detail.** `zoomView.ts` turns a zoom
state into data the canvas paints: siblings dimmed to 25%, the focused task labelled, the focus
ring on the task or the run, the branch glow in `--remedy-state-current`, and a camera per level
that `ForceBrainGraph.tsx` moves to under a lock, so its own camera move is never read as a wheel.
`useSemanticZoom.ts` holds the state, walks back on Escape unless a text field or a dialog has the
key, and reconciles on every graph change; `ZoomBreadcrumbs.tsx` is the chip top-left of the stage
(DECISION F023 D2). The run detail's missing facts were a named prerequisite: the route
`/api/jobs/<job>/task-runs/<task_id>/rounds`, built by `packages/orchestration/run_rounds_view.py`
from the run report the task record points at, serves each round's number, kind, duration, verdict
and builder tokens and nothing else, and `apps/ui/src/api/taskRunRounds.ts` with the
`loadTaskRunRounds` door reads it (DECISION F023 D3). `runDetailModel.ts` words each fact or the
reason it is missing, and `RunDetailPopover.tsx` shows them beside the run the L2 camera centred,
with Open diff, Why, and a Rerun disabled with its reason visible (DECISION F023 D4).

**T003 — evidence, links, clusters, budget, live run.** `EvidencePanel.tsx` is the L3 side panel on
T5_F023.md's binding CSS, its shadow the new token `--remedy-shadow-panel`, its tabs from
`evidencePanel.ts` loading only the open one, and the run detail's Open diff and Why open it on
their tab (DECISION F023 D5). `zoomDeepLink.ts` and `useZoomDeepLink.ts` restore
`?focus=&level=&tab=` through the machine's own events and keep the URL in step with
`history.replaceState`, with no router; `clusterExpansion.ts`, through `buildBrainLayout`'s optional
second argument, gives the focused task's '+N' chip back its runs and returns it at L0; and the
camera waits for the canvas, so a restored level gets its camera (DECISION F023 D6). The frame
budget and the live end-to-end are DECISION F023 D7.
