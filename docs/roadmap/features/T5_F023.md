## Goal & Done
One mental model from organism to evidence: a zoom state machine
{level, focusId} drives L0 (job core + task ring, runs as branch
glow) → L1 (focus task expanded, siblings 25% dim) → L2 (run
popover: verdict, tokens, duration, retries, diff/why/rerun
buttons) → L3 (EvidencePanel side panel: tabs diff | prompt trace
| chat) — with wheel thresholds, click equivalence, breadcrumbs,
Esc walkback and cluster expansion, at the stage-1 perf budget.
DONE when every transition path (wheel, click, breadcrumb, Esc)
lands the goldened state, the L2 buttons wire to their real
backends or render the honest not-yet pattern, clusters expand
per rule, and 60 fps holds at 500 nodes on the perf fixture.

## How it fits (binding interaction spec, restated)
useSemanticZoom state machine {level, focusId}. Wheel thresholds
with hysteresis (zoom-in on a node >1.6, out <0.8), click = the
same transitions, breadcrumbs Job > Task > Run, Esc walks back,
clusters above 8 children ('+12' expands). Perf budget: 60 fps at
500 nodes (stage-1 scope). EvidencePanel CSS core:
```css
.evidence-panel{position:fixed;right:0;top:0;bottom:0;width:min(560px,44vw);
  background:var(--remedy-bg-2);border-left:1px solid var(--remedy-line);box-shadow:-18px 0 40px rgba(37,50,79,.08);
  display:flex;flex-direction:column;animation:slideIn .22s ease}
```
Level semantics render on the reducer's model (F019) with the
glyph language (F020); L2/L3 CONTENT comes from evidence
endpoints (run verdicts, token actuals, diffs, prompt traces —
all existing artifacts served read-only; inventory the endpoints,
add thin read routes where missing as named prerequisite orders).

## Design (suggested shape around the binding spec)
- The state machine as a pure store module (transitions
  goldenable headless): enter(level, focusId) validated against
  the model (focusing a nonexistent node is a no-op with a debug
  note); hysteresis lives in the wheel adapter, not the machine.
- L1 dimming/expansion and L0 branch-glow are render-layer
  effects driven by {level, focusId} — no model mutation.
- L2 popover: anchored per reference; buttons — diff → L3 diff
  tab; why → L3 prompt trace scrolled to the verdict; rerun →
  the write channel's command IF exposed, else the disabled+
  tooltip pattern (check the channel's exposed list — growth is
  per-feature).
- L3 EvidencePanel: tabs lazy-load their endpoint; chat tab is
  the not-yet pattern until its feature. Deep-linkable state
  (?focus=&level=) for the timeline and feed jumps.
- Cluster expansion: '+N' nodes expand into their children at
  L1 focus per graph_spec's rule; collapse on unfocus.

## Task slicing
- **T001** the state machine + transition goldens (every path
  matrix: wheel in/out at boundaries, clicks, Esc chains,
  breadcrumb jumps, invalid focus).
- **T002** render effects (dim, glow, expansion) + L2 popover
  with real endpoint wiring/not-yet buttons + fixtures.
- **T003** EvidencePanel + lazy tabs + deep links + cluster
  expand/collapse + the perf fixture at 500 nodes (numbers
  recorded) + the live end-to-end.

## Acceptance
- Transition matrix goldens exact; hysteresis boundaries tested
  both sides. L2 data matches evidence fixtures; every button
  either works or honestly says when it will. Deep links restore
  state. Perf fixture ≥60 fps stage-1 (recorded; failing it opens
  the stage-2 conversation per the F019 decision, no silent
  degrade).

## Edge cases & assumption defaults (A9)
- Focus on a node that clusters away mid-stream: focus follows
  into the cluster's expansion or walks up one level with a note
  (never a dangling focus). Keyboard: Esc chain is binding; full
  keyboard nav is the a11y feature's scope later — the machine's
  API doesn't preclude it.
