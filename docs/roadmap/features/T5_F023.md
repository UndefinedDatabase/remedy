## Design
useSemanticZoom state machine {level, focusId}: L0 organism (job core + task ring, runs as branch glow), L1 focus task expanded (siblings 25% dim), L2 run popover (verdict, tokens, duration, retries, buttons diff/why/rerun), L3 EvidencePanel side panel (tabs diff | prompt trace | chat). Wheel thresholds with hysteresis (zoom-in on a node >1.6, out <0.8), click = the same transitions, breadcrumbs Job > Task > Run, Esc walks back, clusters above 8 children ('+12' expands). Perf budget: 60 fps at 500 nodes (stage-1 scope). EvidencePanel CSS core:
```css
.evidence-panel{position:fixed;right:0;top:0;bottom:0;width:min(560px,44vw);
  background:var(--remedy-bg-2);border-left:1px solid var(--remedy-line);box-shadow:-18px 0 40px rgba(37,50,79,.08);
  display:flex;flex-direction:column;animation:slideIn .22s ease}
.evidence-tabs{display:flex;gap:4px;padding:10px 12px;border-bottom:1px solid var(--remedy-line)}
.evidence-tab[aria-selected=true]{background:var(--remedy-card);border-radius:10px 10px 0 0;color:var(--remedy-blue-strong)}
@keyframes slideIn{from{transform:translateX(24px);opacity:0}}
```
