# T15_F228 — Counterfactual cost replay
**Tier 15 · Depends on: F140, F110, F158, F074 · Blocks/used by: F222 grounding; routing decisions with numbers**

## Goal & Done
See ROADMAP.md F228; the Done criterion there is binding.

## Context (existing code & prior features)
F140 replays runs structurally; F158 normalizes prices; F074 provides class distributions.

## Design
`remedy stats whatif <job> --routing <alt>`: deterministic shares recomputed for real (pipeline costs); LLM shares per task replaced by a CALIBRATED estimate for the alternative worker (the class's F074 band x the target worker's F158 price, plus a repair expectation from F133 trust) -> a report 'estimated X-Y EUR instead of Z (measured)', every line labeled basis=measured|estimated. Sensitivity: the report states what share is estimation (%). It consumes F140 artifacts exactly; no LLM calls re-execute.

## Task slicing
T001 the replay cost decomposition + estimate substitution + the report + tests (a synthetic job with known bands). T002 the sensitivity disclosure + the CLI + a golden.

## Acceptance & tests
The report golden is stable; measured shares equal the ledger exactly; the estimated-share percentage is correct; a class without minimum-n F074 data says 'not estimable' instead of a number.

## Risks / anti-goals
Never phrase 'would have cost' without a band + basis (the renderer enforces the wording); no automatic routing change from this report (F232 proposes; humans switch).
