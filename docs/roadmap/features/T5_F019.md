## Design
Stage decision (binding): stage 1 = react-force-graph-2d (existing dependency; nodeCanvasObject glyphs, linkDirectionalParticles, zoom API). Stage 2 (PixiJS v8) ONLY if the F044 budget measurably fails -> F233. Data model brainOntology.ts:
```ts
type NodeKind='job_core'|'task'|'builder_run'|'review_run'|'repair_run'|'test_run'|'synapse'|'artifact'|'cluster';
type NodeState='open'|'planned'|'in_progress'|'pass'|'fail'|'blocked'|'vetoed';
interface BrainNode{id:string;kind:NodeKind;state:NodeState;parentId?:string;seq:number;meta:Record<string,unknown>}
```
useBrainStream folds SSE events into nodes/links. Materialization: plan.task_created -> task nodes sprout from the core (spring 420 ms, glow pulse 600 ms); run.started -> run node; run.tool_call -> synapse micro-nodes THROTTLED: >4/s aggregate into a counting cluster (+n); artifact.created -> artifact node docked to its run. prefers-reduced-motion: fade instead of spring, no particles.
