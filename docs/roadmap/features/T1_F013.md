# T1_F013 — Job-Intake
**Tier 1 · Abhängigkeiten: F146, F005 · Blockiert: F014, F056, F069**

## Ziel & Done
Prosa-Auftrag + Anhänge → strukturierter Job. Done: `remedy do "…"` erzeugt ohne
Handarbeit ein valides Job-Objekt.

## Design
- `packages/orchestration/job_intake.py`: LLM-Call (Sonnet, Schema F005 `JobIntake`:
  goal, context, constraints[], anti_goals[], attachments[], size_hint S|M|L|XL,
  mission_candidate:bool + Begründung — Grundlage F056-Entscheidung).
- Anhänge: Pfade werden gehasht + nach `~/.remedy/projects/<pid>/jobs/<jid>/inputs/`
  kopiert; PNG → design_reference-Kandidat (F087).
- Fehlende Pflichtangaben → Klärblock-Einträge (F034), NIE interaktive Rückfrage im CLI.

## Task-Schnitt
- T001: Schema + intake.py + Fixture-Tests (5 Prosa-Beispiele → erwartete Objekte).
- T002: CLI-Anbindung in golden.do + inputs-Ablage.

## Akzeptanz & Tests
- Golden-Fixtures deterministisch mit Fake-Provider; size_hint plausibel (Heuristik-Test).

## Risiken / Anti-Ziele
- Kein Intake-„Wizard"; keine Halluzination von Constraints (nur Explizites + Referenz).
