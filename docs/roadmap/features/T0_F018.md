# T0_F018 — Budgets & stop conditions
**Tier 0 · Depends on: F003 · Later integrates: F014 carries budgets/stop in the Flight Plan (CLI flags + config defaults until then) · Blocks/used by: F046, F104, F116**

## Goal & Done
See ROADMAP.md F018; the Done criterion there is binding.

## Context (existing code & prior features)
No budget concept exists; long runs could burn unbounded money.

## Design
Flight-plan fields budgets{usd?,tokens?}, stop{all_green,max_cycles?,deadline?}, report{level}; defaults from config, CLI flags override. budget_guard.check(job) at the F011 safe points; outcomes budget_exhausted|deadline_reached + checkpoint. Hard USD enforcement lands with F003 actuals; until then token estimates WITH labels. SSE budget.tick {spent, limit, basis}.

## Task slicing
T001 model + guard + safe points + tests (mini budget stops after task 1). T002 budget.tick emitter + CLI flags.

## Acceptance & tests
Deterministic stop order (first limit wins; tie: budget before deadline); the basis field is mandatory everywhere.

## Risks / anti-goals
Never render estimated as actual (P6).
