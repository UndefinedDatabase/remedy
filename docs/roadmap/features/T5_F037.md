## Goal & Done
Changes become readable, not just present: the server serves
structured diff JSON (files/hunks/lines with intraline markers), the
client renders it with syntax highlighting, a file sidebar with
change stats, hunk collapse and virtual scrolling beyond 2k lines —
the reading surface the L3 evidence panel's diff tab and later
hunk-approval build on. DONE when fixture diffs of every shape
(adds, deletes, renames, binary, huge) render per the binding CSS,
intraline markers highlight word-level changes, performance holds on
the 10k-line fixture, and the JSON contract is versioned for the
hunk-id feature that follows.

## How it fits (inspect current shape before building)
Diffs exist as evidence artifacts (the applicator's changes and git
diffs on the job branch) — the server side PARSES those into the
structured JSON (one parser, unified-diff input, tested against a
corpus; renames and binary markers handled explicitly), served as a
read endpoint per task/attempt. Hunk identity (stable ids) is the
NEXT feature's contract — this viewer assigns provisional sequential
ids and documents that F033 replaces them with content-hash ids (the
JSON's version field makes the handoff explicit). Language bundles
lazy-load (bundle-budget discipline from the perf feature applies).

## Design (binding specifics)
- JSON contract v1: {files: [{path, old_path?, status
  (modified|added|deleted|renamed|binary), stats {+,-}, hunks:
  [{id, header, lines: [{kind (ctx|add|del), old_ln?, new_ln?,
  content, intraline: [[start,len]]?}]}]}]}.
- Client, binding CSS core:
```css
.diff-line{display:grid;grid-template-columns:56px 56px 1fr;font:12.5px/1.6 ui-monospace,monospace}
.diff-line.add{background:rgba(56,217,169,.12)} .diff-line.del{background:rgba(247,103,7,.10)}
.diff-line .ln{color:var(--remedy-ink-soft);text-align:right;padding-right:10px;user-select:none}
.hunk-head{background:var(--remedy-bg-2);color:var(--remedy-ink-soft);padding:4px 12px;font-size:11px;letter-spacing:.08em}
```
  File sidebar (paths + stats bars, click scrolls), hunk collapse
  (collapsed by default beyond a size threshold), virtual scrolling
  >2k lines, syntax highlight via lazy language bundles (a small
  supported set; unknown languages render plain — honest, fast),
  intraline emphasis on the marked spans.
- Hunk checkboxes: rendered SPACE reserved but absent until F033
  (the contract note in the component).

## Acceptance
- Corpus goldens exact incl. renames/binary placeholders. Intraline
  spans match a word-diff fixture. 10k-line fixture within the perf
  budget (recorded). Unknown language renders plain without a
  bundle fetch. The JSON version field present; provisional-id note
  documented for F033.

## Edge cases & assumption defaults (A9)
- Diffs against attempts (rerun fans): the endpoint takes an
  attempt parameter; attempt-vs-attempt diffs are a later
  convenience (out of scope, noted). Extremely wide lines: soft
  wrap per the reference's code treatment; horizontal scroll as
  fallback — never truncation.
