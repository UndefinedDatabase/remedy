## Design

Tone matters: it renders as a CONTRIBUTION record, not a blame sheet (wording review is part of acceptance).

## Task slicing
T001 aggregator + CLI + reconciliation tests against the audit. T002 the UI tab + export + a wording pass.

## Acceptance & tests
Numbers equal the audit (property over a fixture history); period filters correct; a viewer sees only their own detail rows (F185 coupling).

## Risks / anti-goals
No performance metrics about people (per-person decision latency is opt-in per team, default off) - a tool, not a surveillance dashboard.
