## Design
`orchestrator_loop.py`: per mission iteration - load the dossier (F071) -> pick/shape the next job (Flight Plan) -> execute (F046) -> evaluate against the milestone DoD -> update the dossier -> write the ledger (Part A generated as a system-prompt block orchestrator_protocol.md). Orchestrator calls use the top-tier model (config). The loop decides WITHIN the mission; it never grants itself new goals (those go through the idea queue with human approval).

## Acceptance & tests
