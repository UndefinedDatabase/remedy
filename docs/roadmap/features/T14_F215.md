# T14_F215 — Distribution & signed binaries
**Tier 14 · Depends on: F086, F165, F200 · Blocks/used by: installability = buyability; M14**

## Goal & Done
See ROADMAP.md F215; the Done criterion there is binding.

## Context (existing code & prior features)
F086 ships a pip release with UI assets; further channels + signatures are missing.

## Design
Channels: a homebrew formula (own tap), a winget manifest, an official OCI image (contains the daemon F200, non-root, healthcheck -> doctor), pip as before. The build pipeline: reproducibility checks (SOURCE_DATE_EPOCH, double-build hash comparison), artifact signatures via the F165 backend (cosign for OCI, detached sigs for archives), an SBOM of the PRODUCT itself (the F170 tooling applied to us). The release index (F204) is produced and signed by this pipeline.

## Task slicing
T001 the OCI image + signature + a fresh-container smoke (install -> demo). T002 brew/winget manifests + a CI matrix (three fresh environments: install -> `remedy demo` green) + the double-build hash check + the product SBOM.

## Acceptance & tests
The three-channel CI matrix passes; cosign verification of the image is documented + tested; the double build is bit-equal (or deviations explained + excluded with a note).

## Risks / anti-goals
No auto-publish without a manual release trigger (the F221 gate first); channel manifests are versioned in the repo.
