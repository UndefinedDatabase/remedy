## Goal & Done
The rendered diff viewer F037 shipped becomes visually complete and measured.
DONE when syntax highlighting is actually rendered rather than merely modelled,
the 10k-line perf budget is measured end to end with its numbers recorded, and
the file sidebar's visual treatment is ruled on by a named design authority.

## How it fits (inspect current shape before building)
F037 is accepted and its Built State section is the inventory — read it first.
Nothing here re-designs the parser or the endpoint; all three pieces sit in the
client. The lazy-bundle model is complete and tested and needs a CALLER, not a
rewrite.

## The three pieces (verbatim scope from amendment A6)

- **T001 — wire the highlighting.** `loadDiffLanguageBundle` is wired into
  `DiffView`. The model is complete and tested — `diffLanguageForPath`,
  `loadDiffLanguageBundle`, the promise cache, the retry-after-rejection rule and
  the supported set — and measured at `82d3d584` it had NO caller outside
  `apps/ui/src/api/diffViewModel.ts` and its two test files. What F037 shipped is
  the model, not the rendered highlight. This closes F037's Goal & Done clause
  "the client renders it with syntax highlighting", which A6 records as UNMET.
- **T002 — measure the 10k-line fixture end to end and RECORD the numbers.** The
  parser is bounded in both dimensions by DECISIONS F037 D5, D6 and D7, and
  virtual scrolling is built and guarded, but no end-to-end measurement was ever
  taken. This closes F037's Acceptance bullet "10k-line fixture within the perf
  budget (recorded)", which A6 records as UNMET. A budget is re-derived from a
  re-measured maximum; it is never raised by hand to make a check pass.
- **T003 — rule on the sidebar's visual treatment.** `DiffFileSidebar.tsx`
  exists and renders paths with change stats. F037 amendment A4 names the three
  design authorities that bind this surface and none of them rules on the
  sidebar, so the ruling is this feature's to make and to record.

## Acceptance
- A diff of a supported language renders WITH highlight spans in the DOM, and an
  unknown language still renders plain without a bundle fetch (the second half is
  already met and proved at the model layer by F037; it must not regress).
- The 10k-line fixture is measured end to end and the numbers are written into
  this file's Built State section — a recorded measurement, not a claim.
- The sidebar's treatment cites the design authority that rules it.

## Do not touch
The diff JSON schema, the read endpoint, hunk-id stability (that is F033's
contract), and apply mechanics. Nothing already built by F037 is removed —
DECISION F037 D11 says so in as many words.

## Orchestrator brief
T001 is the smallest and unblocks the visible half of the Goal; do it first.
T002 needs a real fixture and a real measurement, never an estimate. T003 is a
ruling to be recorded, not code.
