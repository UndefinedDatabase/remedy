# T1_F052 — Self-healing test rounds
**Tier 1 · Depends on: F046, F003 session ids · Blocks/used by: cycle robustness**

## Goal & Done
See ROADMAP.md F052; the Done criterion there is binding.

## Context (existing code & prior features)
Trivial test breaks would otherwise stop unattended cycles cold.

## Design
After a cycle verify with failing tests: up to 2 auto-repair rounds REUSING the existing repair loop (A6) with the test-output digest as findings; then the cycle fails with a post-mortem (F010).

## Task slicing
T001 hook + round cap + tests (trivial break heals; stubborn break stops after 2).

## Acceptance & tests
The trivial injected break heals unattended; rounds are counted in the cycle report; protected paths stay untouched even during healing (F017 applies).

## Risks / anti-goals
No repair on protected paths; no third round, ever.
