## Goal & Done
Pixels converge on the reference, honestly: the loop runs build →
capture → compare+review → repair until the target (default SSIM ≥
0.90 AND zero high-severity findings; configurable) or max_rounds
(default 4) — every round archives shot_n and findings_n so the
improvement path itself is sales material; an abort writes an
honest residue report of what still deviates. DONE when a fixture
UI task converges within rounds on the fake stack (round artifacts
complete), the dual target is enforced exactly (metric AND
findings), abort produces the residue report with the remaining
findings and final numbers, and the loop composes existing repair
machinery rather than growing its own.

## How it fits (inspect current shape before building)
This is the cycle executor's design-verify sibling: verification =
capture+compare+review for the task's design_refs/viewports; repair
= the EXISTING repair loop fed with visual findings as findings
(the fix_hints are the repair prompt's substance — the self-healing
feature's trigger pattern, different findings source, same bounded
mechanics; the round cap here is the design-specific budget,
distinct from test-repair rounds — two counters, documented).
Rounds respect budgets, fences, stops and the safe points like all
provider work; capture unavailability (extra not installed)
degrades the loop to unavailable-with-message, never to fake
convergence.

## Design (suggested shape)
- Loop per UI task (or per job design phase — the plan decides
  granularity via task structure): round = ensure runtime up
  (harness) → capture the task's viewports → compare per reference
  → review → target check → if unmet and rounds remain: repair
  round with the findings (visual findings + metric summary) →
  again.
- Target: BOTH conditions (config: ssim_target, blocking severity
  level); per-reference-and-viewport targets must ALL pass
  (partial passes reported per pair).
- Archive: rounds/n/{shot_*.png, comparison.json, verdict.json,
  repair evidence} — the improvement path; the report renders the
  round strip (thumbnails, numbers per round — the sales
  artifact).
- Abort/residue: max_rounds hit → the task fails its design DoD
  check (a DoD kind visual_fidelity registers — the gate
  integration) with residue.md: remaining findings, final numbers
  per pair, the round trend — honest distance, no rounding up.
- Convergence honesty: a round that worsens the metric is recorded
  as such (regression within the loop is data; the trend renders
  whatever happened).

## Task slicing
- **T001** the round loop + dual target + per-pair accounting +
  archive layout + unit tests with scripted compare/review fakes
  (converges in 2; never converges → abort at 4; worsening round
  recorded).
- **T002** repair integration (findings feeding, the separate
  round counter, safe-point compliance) + budget/stop tests
  mid-loop.
- **T003** the visual_fidelity DoD kind + residue report + the
  report's round strip + the end-to-end on the fixture (doctored
  → converged; impossible target → residue golden).

## Acceptance
- Scripted convergence/abort/worsening fixtures exact; archives
  complete per round. Dual target: metric-pass with a high
  finding does NOT pass (the AND test). Stops/budgets honored
  mid-loop. Residue golden; the DoD gate holds the job open on
  fidelity failure like any blocking check.

## Edge cases & assumption defaults (A9)
- Multiple references/viewports with mixed results: the per-pair
  table is the truth; the strip shows the worst pair prominently.
  Flaky captures (animation missed): the capture determinism
  levers apply; a round whose shot differs wildly from its
  predecessor without code changes flags capture_instability
  (investigate, don't chase pixels).
