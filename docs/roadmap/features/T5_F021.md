## Design
humanize.ts catalog: event -> line ('reads file X', 'runs pytest (attempt 2)', 'reviewer: 3 findings'); NowCard shows the newest action with an activity dot; feed rows carry seq and click-jump to their node. The steering input renders but stays disabled with an honest tooltip until F030. CSS core:
```css
.feed{width:340px;max-height:52vh;overflow:auto;border-radius:var(--remedy-radius-lg);
  background:var(--remedy-card);backdrop-filter:blur(14px);box-shadow:var(--remedy-shadow-soft)}
.feed-row{display:flex;gap:10px;padding:9px 14px;font:500 13px/1.45 var(--remedy-font-ui);color:var(--remedy-ink)}
.feed-row .t{color:var(--remedy-ink-soft);font-variant-numeric:tabular-nums;font-size:11px}
.now-card{border-left:3px solid var(--remedy-live)}
```
