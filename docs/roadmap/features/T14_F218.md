# T14_F218 — Trial mode
**Tier 14 · Depends on: F213, F214, F060 · Blocks/used by: the sales funnel**

## Goal & Done
See ROADMAP.md F218; the Done criterion there is binding.

## Context (existing code & prior features)
The F213 license mechanics carry editions; a trial is missing.

## Design
A trial license = a normal F213 file with trial:true + caps {max_jobs, max_budget_eur}: enforcement rides the EXISTING budget guards (F018/F104 - no parallel mechanism, A6) plus a job counter. The 'TRIAL' watermark is honest but calm: a header line on all reports/certificates + a cockpit badge; cryptographically co-signed (a field inside the signed manifest - a trial certificate is provably a trial). Expiry follows the F213 stages; all data stays usable.

## Task slicing
T001 trial fields + cap enforcement through existing guards + the counter + tests. T002 the watermark across all export paths (a corpus scan: report/certificate/dossier/story) + the manifest field + verify reports trial.

## Acceptance & tests
Caps stop exactly (budget-guard tests reused); the watermark corpus is complete; verifying a trial certificate reports trial=true.

## Risks / anti-goals
No feature castration (trial = full capability, limited quantity - quality judgments need real features); the watermark is never hidden and never removable without breaking the signature.
