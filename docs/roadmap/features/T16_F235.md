## Goal & Done
See ROADMAP.md F235; the Done criterion there is binding.

## Context (existing code & prior features)
The F024 scrubber replays graph states; F029 keeps stash SHAs per task end; the DiffViewer renders structured diffs.

## Design
While scrubbing to seq s: an EvidencePanel tab 'state' shows a ghost diff = workspace(snapshot at the mapped task boundary) vs. final (a git diff between the stash SHA and the result branch, served by /api/jobs/{jid}/ghost?seq=s, cached per task boundary - scrubbing WITHIN a task keeps the same ghost, honestly labeled 'state after task Txxx'). Rendering reuses the DiffViewer with a ghost style (reduced saturation; a 'historical state' watermark). No checkout; a pure diff view.

## Task slicing
T001 the ghost endpoint (SHA resolution + diff JSON + cache) + tests. T002 the panel tab + scrub coupling + ghost styling + playwright (3 scrub points show correct intermediate states via hash comparison).

## Acceptance & tests
Ghost diffs hash-match snapshot truth; task granularity is clearly communicated (a label test); scrubbing stays fluid (ghosts load async; the graph never blocks).

## Risks / anti-goals
No file restore from this view (that is F136, with audit); a ghost is never confusable with a live diff (the visual separation is a review criterion).
