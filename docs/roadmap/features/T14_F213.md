# T14_F213 — Licensing & activation
**Tier 14 · Depends on: F165 signing, F173 · Blocks/used by: commercialization; F214/F218**

## Goal & Done
See ROADMAP.md F213; the Done criterion there is binding.

## Context (existing code & prior features)
F165 provides Ed25519 infrastructure; nothing license-related exists.

## Design
A license = a signed file remedy.license (Ed25519 against an embedded vendor public key): {licensee, edition, seats, issued, expires, features_extra[]}. Checked at startup + daily in the daemon (locally; correct without wall-clock tricks: an expires comparison, NO phone-home). Expiry behavior is staged: a 30-day warning phase -> expired: the cockpit goes read-only + no new jobs; running jobs finish cleanly; data stays fully accessible (NEVER bricking, NEVER a data hostage). `remedy license show|install <file>`.

## Task slicing
T001 format + verify + the state machine (valid/warn/expired/tampered) + tests. T002 enforcement points (job start, cockpit mode) + the CLI + a capture test (zero egress).

## Acceptance & tests
Every license state behaves exactly as specified; a tampered file is treated as absent + a clear message; the capture proves offline checking.

## Risks / anti-goals
No copy-protection theater (seats are a trust field + display, not spyware enforcement); the core edition (F214) stays fully functional without any license file.
