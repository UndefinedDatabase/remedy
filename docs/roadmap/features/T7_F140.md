# T7_F140 — Bit-exact evidence replay
**Tier 7 · Depends on: F012, F004 · Blocks/used by: F228, tamper evidence**

## Goal & Done
Evidence proves itself: `remedy verify --replay` re-executes
fake-provider runs from their recorded streams and must reproduce
the artifact hashes bit-exactly; for real runs, every deterministic
pipeline step replays and LLM outputs hash-verify against the
recorded streams — with documentation stating plainly what this
does and does not prove. DONE when a recorded fake run replays to
identical hashes (and a tampered artifact fails naming the file),
a real-run verification distinguishes replayed-deterministic from
hash-verified-recorded per step, nondeterminism found in a
supposedly deterministic step is reported as a finding (the
replay is also a determinism test of Remedy itself), and the
honesty document ships.

## How it fits (inspect current shape before building)
The pieces were built for this: the run manifest pins inputs, raw
stream evidence (F004) records provider I/O verbatim, per-call
directories hold prompts/outputs, the certificate's hash manifest
covers members. Replay = re-running the pipeline with a
replay-provider (an adapter that SERVES the recorded streams
keyed by call sequence/hash — verify how the fake provider in
tests is injected; the replay provider is its production-grade
sibling, one injection seam) inside a scratch worktree from the
manifest's base commit. Deterministic steps (planning skeleton,
applicator, renderers, DoD runners on fixed inputs, report) must
byte-match; recorded LLM outputs hash-verify (they are inputs to
the replay, their integrity is what's proven). The honesty doc:
this proves internal consistency and tamper-evidence — NOT that
the LLM would answer the same today, and NOT provenance (the
certificate's not-a-signature line kin).

## Design (suggested shape)
- The replay provider: serves stream N for call N after verifying
  the outgoing prompt's hash matches the recorded one (a prompt
  mismatch means Remedy's assembly changed — reported as
  drift:prompt_assembly with the segment-manifest diff, the
  cache-ordering evidence earning its keep).
- `remedy verify --replay <job|certificate>`: manifest check →
  scratch worktree at base → pipeline re-run with the replay
  provider → per-artifact hash comparison → the verdict table
  {artifact, replayed|hash_verified, match|MISMATCH|drift} —
  exit nonzero on any mismatch with the member named.
- Tolerated nondeterminism: a documented allowlist (timestamps
  inside artifacts normalize via the comparison's
  canonicalization — timestamps are recorded fields, not hash
  poison; the canonicalizer is explicit and versioned).
- Scope tiers: fake-run replay = full bit-exact; real-run =
  deterministic steps replayed + streams hash-verified; the
  verdict table labels each row's tier.
- CI: the demo recording replays in CI (the standing determinism
  canary — cheap, meaningful).

## Task slicing
- **T001** the replay provider (seam verification, prompt-hash
  gate, stream serving) + unit tests.
- **T002** the replay pipeline + canonicalizer + verdict table +
  fixtures (clean fake run bit-exact; tampered artifact named;
  prompt-assembly drift detected via a deliberate segment change).
- **T003** real-run tiering + the honesty document + certificate
  integration (verify --replay accepts bundles) + the CI canary +
  the end-to-end.

## Acceptance
- Fake-run replay bit-exact; each tamper class (artifact, stream,
  manifest) fails naming the member. The deliberate-drift fixture
  reports drift:prompt_assembly with the manifest diff. The
  canonicalizer's allowlist is closed and versioned (grep guard).
  The honesty doc exists, linked, and its claims match the
  verdict-table semantics (a docs test).

## Edge cases & assumption defaults (A9)
- Runs spanning retired code paths (old Remedy versions): replay
  requires the recorded remedy_git_sha's behavior — v1 replays on
  the CURRENT version and reports version drift honestly when
  hashes diverge with the sha mismatch noted (full versioned
  replay is F228 territory, stated). Parallel runs: replay
  serializes (determinism first; the lane timings differ, the
  artifacts must not).

## Orchestrator brief

(how fakes inject) is the opening deliverable. The honesty
document's what-this-proves table goes verbatim into T003 and is
reviewed word by word.
