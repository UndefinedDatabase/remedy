# T1_F079 — Context handoffs
**Tier 1 · Depends on: F071, F047 · Blocks/used by: long missions across sessions**

## Goal & Done
See ROADMAP.md F079; the Done criterion there is binding.

## Context (existing code & prior features)
Session and context switches lose knowledge; self-build spans many sessions by nature.

## Design
`handoff.py`: on context/session switches build a package of dossier + latest checkpoint + open decisions as handoff.json + a rendered prompt block. Quality is MEASURED: a 10-fact recall eval (facts seeded before, queried after).

## Task slicing
T001 package + eval harness + tests (fake provider with a simulated memory boundary).

## Acceptance & tests
>=9/10 facts survive the handoff.

## Risks / anti-goals
The handoff never replaces the ledger (audit lives there).
