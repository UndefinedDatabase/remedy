## Design
Route /memory: grid of card tiles (lands with the Tier 5 shell; the data/curation layer works CLI-first until then). CSS core (tokens only):
```css
.card-tile{width:210px;height:290px;border-radius:16px;background:var(--remedy-card);
  box-shadow:var(--remedy-shadow-soft),var(--remedy-shadow-inset);display:flex;flex-direction:column;
  overflow:hidden;transition:transform .18s ease}
.card-tile:hover{transform:translateY(-4px) rotate(.4deg)}
.card-tile .band{height:44px;display:flex;align-items:center;padding:0 12px;
  font:600 12px/1 var(--remedy-font-ui);letter-spacing:.08em;color:#fff}
.band.architecture{background:var(--remedy-blue-strong)} .band.convention{background:var(--remedy-state-current)}
.band.lesson{background:var(--remedy-orange-400)} .band.decision{background:var(--remedy-state-open)}
.band.risk{background:var(--remedy-red-500)} .band.component{background:var(--remedy-state-done)}
.card-tile .rank{position:absolute;top:8px;right:8px;width:22px;height:22px;border-radius:50%}
.rank.bronze{background:#b08d57}.rank.silver{background:#aab4c4}.rank.gold{background:#e5b53b}.rank.platinum{background:linear-gradient(135deg,#9db8ff,#e2e8ff)}
```
Tile: type band, title, uses counter, origin chip, subtle rank dot. Detail sheet: body render, usage history (jobs), actions edit/archive/pin/attach/detach - all through the command catalog.
