# T2_F318 — Fragen an ein Projekt, nur lesend (a question to a project, read-only)
**Tier 2 · Depends on: F253 (the public HTTP API), F317, amend1023-universe-trust (the host_tools client) · Blocks/used by: the universe's apps that let Claude Code look at a project without changing it**

> Registered 2026-10-26 by operator amendment amend1026-go-live-and-ask (Part E2), directly after
> F317, and built and closed by that amendment itself.

## Goal & Done
A client granted `host_tools` asks a question about one of its projects over the public HTTP API,
and Remedy answers it through the Claude Code CLI that may only read the repository: the tools
Read, Glob and Grep and no other; no Edit, no Write, no Bash, no git. The answer comes as Markdown
with the tokens and calls it used and its model; the question, the answer and every tool call are
kept under the data root, never in the project.

## What it rests on (operator amendment amend1026-go-live-and-ask)
- Part C1: `GET /api/v1/projects` (`remedy client projects`).
- Part C2: `POST /api/v1/projects/{project}/ask` (`remedy client ask`), `packages/orchestration/project_ask.py`.
- Part C3: tests prove the command line names only the three reading tools and the repository is
  unchanged after an ask (`tests/orchestration/test_project_ask.py`).

## Acceptance
- The client `orb-universe` asks Remedy's own project "Welche Datei entscheidet, ob ein Auftrag ein
  Job oder mehrere wird, und wie?" over HTTP; the answer names `scope_decision.py`.
- The evidence lies under `evidence/current/amend1026_ask/` and shows the real call, its tool calls
  and its tokens; no manual attestation.

## Do not touch
The write tools of every other claude-cli role; attachments (the API has no upload route).
