**Tier 1 · Abh.: F013, F014 · Prinzip: P7/A9**

## Ziel & Done
Echte Unklarheiten → EIN Klärblock vorab; Laufzeit: Referenz ist Gesetz, sonst
assumption_log. Done: 3 Unklarheiten → 1 Klärblock, 0 Laufzeitfragen.

## Design
- Intake/Planner klassifizieren Lücken: `blocker` (widersprüchlich/Pflicht fehlt) →
  clarifications[] im Flight Plan; `default_ok` → assumption_log-Eintrag
  {topic, default, source:'reference'|'convention'|'token'} in Task-Evidence.
- Klärblock-UI: nummerierte Fragen mit Kurz-Antwortfeldern IM FlightPlan.tsx (eine
  Karte, ein Submit → approve_plan mit answers{}); CLI: nummerierte Prompt-Liste einmalig.
- Harte Regel im Builder-Prompt-Header: „Stelle keine Fragen. Bei Unklarheit: Referenz
  wörtlich; sonst dokumentierter Default in assumption_log."

## Task-Schnitt
- T001: Klassifikation+assumption_log-Writer+Tests (3-Unklarheiten-Fixture).
