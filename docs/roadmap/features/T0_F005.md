## Goal & Done

## Context (existing code & prior features)
reviewer.py and llm_planner.py parse free text with fallbacks; format errors cause repair rounds (wasted tokens, error class parse).

## Design
Package `packages/orchestration/schemas/` with pydantic models (review_verdict, plan_output, design_spec prepared) + to_json_schema() export + schema_v field. Provider calls pass --json-schema; responses validate; a validation failure is error class parse with max 1 retry carrying the error hint.

## Task slicing
T001 schemas package + goldens + tests. T002 reviewer on the schema path (old parser behind a flag). T003 planner on the schema path; remove fallback after 5 green runs.

## Acceptance & tests
Property round-trip per model; invalid answer -> 1 retry -> classified failure; prompt trace shows schema_v per call.

## Risks / anti-goals
Keep schemas small (tokens). No mega-schemas, no new taxonomies (A6).
