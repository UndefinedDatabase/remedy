# T8_F158 — Cost normalization & price catalog
**Tier 8 · Depends on: F103, F151 · Blocks/used by: F159, F222, F228**

## Goal & Done
See ROADMAP.md F158; the Done criterion there is binding.

## Context (existing code & prior features)
The ledger stores costs from F003; foreign workers may report only token counters.

## Design
packages/workers/pricing.py + versioned pricing/<adapter>.toml (input/output/cache prices per model, currency, valid_from, source URL as a comment). Ledger rows gain raw_counters{} + normalized_eur + pricing_version + basis (provider_reported | catalog_computed); provider-reported wins, the catalog cross-checks (>5% deviation warns). A stale catalog (>60 days) warns in stats, never blocks. `remedy worker pricing update` imports maintained catalogs.

## Task slicing
T001 catalog format + calculator + ledger fields + tests (both bases, deviation warning). T002 stats/ticker show the basis; catalogs for claude_cli/codex/gemini/local(0).

## Acceptance & tests
Triangle test counters x catalog == normalized; a catalog update NEVER changes old entries (the price state freezes per call, tested); currency conversion pinned per catalog version.

## Risks / anti-goals
No live price APIs (determinism/air-gap); catalog upkeep is deliberately manual with sources (P6).
