## Goal & Done
Power and discipline in one feature: Cmd+K opens a palette over the
command catalog plus fuzzy node jump (the omni-bar in ux_design.png
— "Ask your agent or jump to anything" — is this palette fused with
the chat entry), j/k/Enter/Esc navigate the graph, and CI enforces
the performance budgets: first paint < 1.5 s, 60 fps at 200 nodes
(trace-metric measured), and a bundle size cap. DONE when the
palette executes exposed commands and jumps with correct scoping,
keyboard navigation covers the documented map, all three budgets
run red/green in CI with recorded numbers, and budget breaches name
their regression source (the bundle report, the trace).

## How it fits (inspect current shape before building)
The palette is a THIN composition: command entries come from the
channel's exposed catalog (schemas drive argument prompts — a
command needing a task id asks via the same fuzzy node search),
node jump reads the reducer's model (fuzzy over id/title/kind),
project switch and '?'/chat entries register too (the omni-bar
routes: text starting like a question → chat; otherwise palette
semantics — the routing rule documented and tested). Keyboard: a
single keymap module (the zoom machine's Esc chain already exists
— extend, don't fork), scoped so inputs never lose their keys.
Budgets: the tooling per frontend conventions (trace-based fps
metric on the 200-node fixture, size-limit-style bundle cap, a
first-paint measurement on the built shell) wired as CI stages
(the ci feature's ui stage grows them).

## Design (suggested shape)
- Palette per the reference (the omni-bar's visual is the spec):
  sections (Commands | Jump | Projects | Help), fuzzy with
  highlighted matches, argument flow from schemas, recent items;
  execution through the channel (audited like any client).
- The question-vs-command routing rule: leading verbs from the
  catalog → command; otherwise → chat with the text prefilled
  (one bar, two brains, honest split — the rule's tests include
  ambiguous fixtures with the documented tie-break).
- Keymap: j/k sibling walk, Enter = zoom-in/select, Esc = the
  zoom walkback, g then p = projects, ? = catalog panel, / or
  Cmd+K = the bar; a keymap cheat overlay on '?' hold (per
  reference).
- Budgets in CI: numbers recorded per run (trend visible), breach
  output names the biggest deltas (bundle: the size report diff;
  fps: the slowest trace spans).

## Task slicing

## Acceptance
- Every exposed command executable from the palette with correct
  argument flows; jump focuses right (fixture ids); routing rule
  goldens incl. ambiguity. Keymap never steals from inputs. CI
  budgets red/green with numbers; a seeded bundle bloat fixture
  names the culprit chunk.

## Edge cases & assumption defaults (A9)
- Commands unavailable in the current state (terminal job): the
  palette shows them disabled with the state reason (the
  channel's refusal vocabulary, pre-empted client-side but still
  server-validated). 200 nodes is the stage-1 budget scope; the
  500-node zoom fixture stays the zoom feature's bar (two
  fixtures, two owners, documented).
