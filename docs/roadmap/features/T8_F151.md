## Design
`packages/workers/adapter_api.py`:
```python
class WorkerCapabilities(TypedDict):
    vision: bool; json_schema: bool; session_resume: bool
    streaming: bool; tool_use: bool; max_context_tokens: int
class WorkerAdapter(Protocol):
    id: str; version: str
    def capabilities(self) -> WorkerCapabilities: ...
    def invoke(self, req: WorkerRequest) -> WorkerResult: ...
    def stream(self, req) -> Iterator[WorkerEvent]: ...   # F004 envelope
    def cancel(self, handle) -> None: ...
    def cost_report(self, result) -> UsageActuals | None: ...
```
WorkerRequest carries prompt_segments (F105 registry order!), attachments, schema (F005), timeout profile (F001), isolation (F152). Registration via the entry-point group `remedy.workers`; selection in config [workers], routing (F110) speaks adapter.model tuples. The existing Claude path is mechanically extracted into claude_cli_adapter.py - behavior-identical, proven by golden comparison against 3 recorded runs.
