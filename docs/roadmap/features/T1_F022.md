## Ziel & Done
Kopfzeile zeigt laufende Kosten/Tokens + Budgetbalken + Restschätzung. Done s. Masterplan.

## Design
- SSE `budget.tick` (F018) alle ≥2 s oder je Run-Ende: {spent_usd, spent_tokens,
  limit_usd?, basis:'actual'|'estimated', eta_band}.
- `MetricsBar.tsx` erweitert bestehende Leiste: fünftes Segment COST:
  `€ 3,42 / 10,00` + schmaler Balken; basis=estimated → Suffix „~" + Tooltip
  („Schätzung — echte Messung ab F003 aktiv"); eta als Band „~25–40 min".
```css
.metric{display:flex;flex-direction:column;gap:6px;padding:0 26px;border-left:1px solid var(--rm-line)}
.metric b{font:800 26px/1 var(--rm-font);color:var(--rm-ink)}

.metric .bar>i{display:block;height:100%;background:linear-gradient(90deg,var(--rm-accent),var(--rm-glow))}
.metric .bar[data-warn="true"]>i{background:linear-gradient(90deg,#FFB05C,var(--rm-warn))}
```
