# T1_F053 — Final & interim report
**Tier 1 · Depends on: F046, F003 · Blocks/used by: F040, F060, human oversight of self-build**

## Goal & Done
See ROADMAP.md F053; the Done criterion there is binding.

## Context (existing code & prior features)
There is no single human-readable account of a run; self-build without reports is unaccountable.

## Design
`run_report.py`: render_report(job, mode=final|interim) -> ONE markdown: per-task results, blocked+why, costs (basis-labeled), decisions open/taken, ownership extract, diff links, recommended next action. Final writes automatically to jobs/<jid>/report.md; `remedy jobs report <id> [--interim]` renders a labeled snapshot of a still-running job.

## Task slicing
T001 renderer + final golden. T002 interim mode against a running fake job + CLI.

## Acceptance & tests
Goldens for both modes; the interim labels itself as a snapshot (P6).

## Risks / anti-goals
ONE report format - no report family (A6 spirit).
