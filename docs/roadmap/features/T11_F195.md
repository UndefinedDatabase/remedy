# T11_F195 — Budgeted fuzzing
**Tier 11 · Depends on: F061 · Blocks/used by: parser/deserializer hardness**

## Goal & Done
See ROADMAP.md F195; the Done criterion there is binding.

## Context (existing code & prior features)
Nothing exists; F010 failure classes and F135 quarantine absorb results.

## Design
packages/verification/fuzz_probe.py: targets = parsers/deserializers in the diff (heuristic: functions bytes/str -> structure; json/yaml/custom formats). An atheris run under a time + corpus budget, seeded from existing fixtures. A crash yields the minimal input as an artifact + a PROPOSED regression test (tests/fuzz_regressions/). DoD kind fuzz is optional and never default (cost).

## Task slicing
T001 the target heuristic + the atheris runner + budgets + tests. T002 crash minimization + the regression test generator + a fixture (a parser with a crash input).

## Acceptance & tests
The fixture crash is found; the minimal input is <1 KB; the proposed regression test is red then green after the fix; the budget holds hard.

## Risks / anti-goals
No endless fuzz farms (a sample, labeled as such); native extensions out of scope in v1 (documented).
