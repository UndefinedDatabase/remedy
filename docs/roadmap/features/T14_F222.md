# T14_F222 — Customer cost calculator
**Tier 14 · Depends on: F074, F158, F103 · Blocks/used by: a sales tool; expectation management**

## Goal & Done
See ROADMAP.md F222; the Done criterion there is binding.

## Context (existing code & prior features)
The F074 calibration bands (P20-P80 per class) and F158 normalization provide the data.

## Design
A cockpit calculator (+ `remedy stats quote --class M --worker codex`): input feature class(es) + worker -> output cost and wall-time bands with the MANDATORY label 'basis: n=<x> runs, P20-P80, as of <date>'; below a minimum n (config, default 20) it says 'insufficient data' instead of a band - NO fantasy numbers. Export as a quote table (md/csv) with a methodology footer. The org variant respects F210 ACLs.

## Task slicing
T001 band queries + the minimum-n rule + the CLI + tests (synthetic histories for both cases). T002 the cockpit UI + export + the methodology footer.

## Acceptance & tests
The calculator reproduces the ledger statistics exactly; n < minimum yields the honest refusal (golden); the export footer is inseparable (enforced in the renderer).

## Risks / anti-goals
No fixed-price suggestions (bands ARE the honesty product); worker comparisons link the scoreboard (F159) instead of editorializing.
