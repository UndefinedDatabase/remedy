## Goal & Done
The study's narration calls run on the local model and are not counted against the order's call budget, or are skipped when the project is already studied and only a manifest changed. The order ledger keeps at least three full rounds of builder and reviewer free for the job; when the order's cap cannot cover that, Remedy says so in one sentence before planning and plans with the smallest size that suffices instead of stopping mid-job.

## What it rests on
- decodeux's words in the order beweis, line U742 / F327 (the workspace's feature file T71_U742.md).

## Acceptance
- A `study_narration` call through the ledger is not counted and never refused.
- A planner call that would leave fewer than three rounds (six calls) for the job is refused with a sentence naming the reserve.
- An order cap below the reserve gives one sentence before planning, and the walk plans one job.
- A studied project where only `package.json` changed skips the narration calls.
