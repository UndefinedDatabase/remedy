## Design
A read-only terminal view (xterm.js) in the EvidencePanel/preview area: tail -f semantics over /api/runtime/{handle}/logs/stream (SSE; the same F008 infrastructure), ANSI colors, search (the xterm search addon), a download button (the whole file). Next to it an ACTION strip built exclusively from the command catalog: restart_preview, stop_preview - NO input handler exists on the terminal (the F009 law: one write door).

## Task slicing
T001 the log stream endpoint + rotation safety (F203) + tests. T002 the xterm embed + search + the action strip + a security test (no onData path exists: grep + an E2E proving keystrokes do nothing except copy/search).

## Acceptance & tests
A log line reaches the display in <1 s; search works over a 10k-line fixture; the security test passes; the download hash-matches the file.

## Risks / anti-goals
No interactive terminal, ever (not even behind flags - stated here and in docs/system/sandbox-model.md); the console shows ONLY F007/F190 processes, never arbitrary host logs.
