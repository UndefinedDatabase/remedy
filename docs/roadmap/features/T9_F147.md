# T9_F147 — Golden-Path-CLI

## Ziel & Done
Drei-Befehle-Mentalmodell: `remedy do "…"`, `remedy`, `remedy ui`. Done: geklontes Repo
→ `remedy init` + `remedy do` = laufender Job <2 Min; Hilfe passt auf einen Screen.

## IST-Bezug
- apps/cli/grouped.py: viele Subcommands, kein Golden Path; Start braucht heute Flags.

## Design
`apps/cli/golden.py` (neue dünne Schicht über bestehenden Kommandos):
- `remedy do "text…" [--design x.png] [--budget-usd N] [--rehearse|--shadow]`
  Ablauf: detect (F146) → Config-Defaults laden (.remedy/config.toml [defaults]
  provider/model/budget, global ~/.remedy/config.toml als Fallback) → Job-Intake (F013)
  → Flight Plan anzeigen (F014; TTY: kompakte Tabelle, `--yes` überspringt) → Start.
- `remedy` (bare): Projektname, aktive Jobs (Status, %,, Kosten heute), letzte 3 Läufe,
  offene Entscheidungen (n) — eine Bildschirmseite, keine Pagination.
- `remedy ui`: startet ui_server falls nötig (Port aus config, F007-Mechanik) und
  öffnet Browser mit `?project=<pid>`.
- Hilfe: `remedy -h` zeigt NUR die drei + „mehr: remedy help all".
