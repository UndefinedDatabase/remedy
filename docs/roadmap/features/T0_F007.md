## Design
`dev_server.py`: RuntimeSpec{cmd,cwd,port,health_path,ready_timeout_s}; DevServer.start/wait_ready/logs/stop (kills the process tree via psutil). Spec per project in .remedy/config.toml [runtime] with autodetection heuristics at init (vite/next/fastapi/uvicorn). CLI `remedy runtime serve|probe|stop`; logs to ~/.remedy/projects/<pid>/runtime.log; free-port fallback returns the effective port.

## Task slicing

## Acceptance & tests
