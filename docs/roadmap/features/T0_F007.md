## Design
`packages/runtimes/dev_server.py`:
```python
@dataclass class RuntimeSpec: cmd:list[str]; cwd:str; port:int; health_path:str="/"; ready_timeout_s:int=60
class DevServer: start() -> None; wait_ready() -> bool; logs() -> path; stop() -> None
```
- Spezifikation pro Projekt in `.remedy/config.toml` `[runtime]` (cmd, port, health_path);
  Autodetektion-Heuristik bei `remedy init` (vite/next/fastapi/uvicorn-Erkennung).
- CLI: `remedy runtime serve|probe|stop`. Log-Capture nach `~/.remedy/projects/<pid>/runtime.log`.
- Port-Kollision: freien Port wählen (Basis+n), effektiven Port zurückgeben (für F090).
