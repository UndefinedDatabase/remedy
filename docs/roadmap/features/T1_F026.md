# T1_F026 — Task-Edit zur Laufzeit
**Tier 1 · Abh.: F009, F025, F015-Validierung**

## Ziel & Done
Wartende/pausierte Nodes umformulierbar (Prompt/Scope/Kriterien); Neustart mit
user_modified_at_runtime. Done: editierter Node baut nach neuer Vorgabe.

## Design
- Command `edit_task{task_id, patch:{title?,intent?,allowed_paths?,acceptance?}}` —
  nur Zustände planned|paused|fail; laufend → 409 („erst pausieren").
- Wirkung: Task-Spec-Version++ (task_spec_v2.json neben Original), Evidence-Vermerk,
  bisherige Run-Kinder bleiben im Graph (Historie!), neuer Run startet als v2.
- UI: L1-Kontextmenü „Bearbeiten" → Editor-Sheet (Titel/Intent/Pfade/Kriterien),
  DAG-Revalidierung wie F015.

## Task-Schnitt
- T001: Versionierung+Command+Tests; T002: Editor-Sheet+SSE.

## Akzeptanz & Tests
- v2-Run-Prompt enthält Patch nachweislich (Prompt-Trace-Assertion); Historie erhalten.
