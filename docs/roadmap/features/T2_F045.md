## Ziel & Done
Siehe Masterplan F045; das dortige Done-Kriterium ist verbindlich.

## Design
`packages/orchestration/loop_spec.py`: LoopSpec{trigger: manual|schedule|event, scope{project, paths?, queue?}, action: job|mission|routine, budget{usd?, tokens?, cycles?}, stop:[all_green|deadline|budget], report: summary|full} als TOML in `.remedy/loops/<name>.toml`. CLI: `remedy loop run <name>|list|validate` (CONVENTIONS-Nachtrag). Validierung per Schema (F005); Loop-Start erzeugt einen normalen Job/Langlauf mit `loop_ref` in der Evidence.

## Task-Schnitt
T001 Spec+Parser+Validate+Tests; T002 CLI+Job-Anbindung.

## Akzeptanz & Tests
Ein Loop-File startet einen definierten Lauf; invalides File liefert praezise Fehlermeldung mit Zeilenangabe.

## Risiken / Anti-Ziele
Keine eigene Cron-Engine v1 (trigger=schedule dokumentiert externen Aufruf via cron/systemd).
