## Design

Regressions become findings with a py-spy flamegraph artifact (py) or a latency distribution plot. Baseline updates only via the explicit command (F098 pattern) showing the delta first.

## Task slicing
T001 the py benchmark runner + baselines + tolerance + tests. T002 the k6 path + flamegraph capture + a fixture (an O(n^2) regression is caught).

## Acceptance & tests
The deliberate regression yields a finding with a flamegraph; noise below tolerance never trips (a 5x stability run); the update command shows the delta.

## Risks / anti-goals
