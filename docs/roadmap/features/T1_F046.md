# T1_F046 — Multi-cycle loop

## Goal & Done
See ROADMAP.md F046; the Done criterion there is binding.

## Context (existing code & prior features)
The bounded executor is deliberately capped at max_cycles=1; long autonomous work is impossible.

## Design
`long_run_executor.py`: while not stop(): plan_delta -> execute task batch -> verify -> checkpoint. Limits (F018) checked at the F011 safe points; a cycle is a coherent batch (max n from config). Statuses: running -> stopped_by_operator | budget_exhausted | deadline_reached | all_green. THE ROLLOUT RULE: default stays 1 cycle until F075 passes.

## Task slicing
T001 loop + stop matrix + a 5-cycle fixture. T002 CLI flags + cycle_reports/ evidence.

## Acceptance & tests
The 5-cycle run ends exactly at its limit; the workspace verifies green; every status transition is covered.

## Risks / anti-goals
Do not lift the 1-cycle default early - the gauntlet is the gate.
