# T11_F188 — API compatibility guard
**Tier 11 · Depends on: F061, F005 · Blocks/used by: semver discipline; F221 gate**

## Goal & Done
Breaking changes stop being surprises: api_compat.py snapshots the
public surface — Python via a griffe-style extractor (signatures,
defaults, exports), TypeScript via a tsc declaration diff — before
and after a job, classifies the delta breaking | additive | patch
by a fixed documented rule table, turns breaking into a decision
with the evidence triple (proof = the diff line, expectation =
semver major or a deprecation-path proposal, downside = consumer
breakage), offers a DoD kind api_compat, and keeps baselines in
.remedy/api_baselines/ with an update command following the
baseline-guard pattern. DONE when the extractors produce stable
snapshots on fixture packages (deterministic serialization —
reruns byte-equal), the classification table covers the documented
change kinds with per-row tests (removed export, narrowed
signature, changed default, added optional parameter, new export),
breaking decisions carry real triples with the exact surface line
quoted, baselines update only through the shown-diff command
(fence-protected like the visual goldens), and both ecosystems
degrade honestly where their tooling is absent.

## How it fits (inspect current shape before building)
The pattern is the visual baseline guard transposed to API
surfaces: goldens (surface snapshots) under a fence-protected
in-repo path, a comparison in the DoD, updates only via the
gated shown-diff command — reuse the guard's structure (the
protected-path registration, the update-command skeleton).
Extractor stance: the Python surface walks importable modules'
public names (module __all__/underscore conventions,
signatures via inspect on the worktree's environment — a
griffe-style dependency is allowed into the quality extra IF the
findings order shows inspect-based extraction insufficient; the
choice is an ADR); TypeScript rides tsc --declaration output
diffing (tsc from the target project's own toolchain — detected,
honest degradation without it, per-ecosystem rows). Scope:
PUBLIC surface only per documented conventions (private paths
configurable — the project says what's public; the config's
surface_roots).

## Design (suggested shape)
- Snapshots: {module → {name → {kind, signature normalized,
  defaults, type text}}} serialized deterministically (sorted,
  versioned schema); per ecosystem one extractor module.
- The rule table (the feature's policy core, documented +
  table-tested): removals/renames/narrowing/required-parameter
  additions/default changes → breaking; new exports/optional
  additions/widenings → additive; doc/type-comment-only →
  patch; unknown shapes → breaking-conservative (stated).
- The DoD kind: compare worktree-after vs baseline → the class
  → breaking blocks pending the decision (options: accept-as-
  major (baseline updates on approval through the gated path) |
  deprecation path (a proposal task skeleton: keep the old
  surface delegating, warn, schedule removal — the planner
  consumes it)); additive/patch report informatively.
- Baselines: .remedy/api_baselines/<ecosystem>.json; `remedy
  api-baselines update` (shown diff, explicit accept, audited).

## Task slicing
- **T001** the Python extractor + deterministic snapshots +
  fixture packages + the ADR on extraction depth.
- **T002** the rule table + classification + per-row tests +
  the TS extractor (tsc detection, declaration diff, honest
  degradation).
- **T003** the DoD kind + breaking decisions (triples with
  quoted lines, both resolution options) + baselines +
  the gated update + the end-to-end (a fixture removing an
  export → blocked → accept-as-major → baseline updated →
  green).

## Acceptance
- Snapshot determinism (rerun byte-equality). The rule table's
  every row fixture-proven; unknowns classify conservative.
  Breaking decisions quote the exact line; both options
  round-trip (the deprecation skeleton materializes as a
  proposal). Baselines fence-protected; updates shown-diff-
  gated and audited. Per-ecosystem degradation honest.

## Edge cases & assumption defaults (A9)
- Generated/vendored surfaces: the shared ignore notion excludes
  them from the public walk. Runtime-constructed exports
  (dynamic __all__): the extractor records what static+import
  inspection sees; the docs state the boundary (dynamic magic
  may hide — conservative honesty). Monorepos: baselines per
  surface root (config lists them).

## Orchestrator brief
Gate on the baseline-guard pattern + the DoD compiler. T002's
rule table is the policy moment — human review before it
freezes. The conservative-unknown rule and the shown-diff
update go verbatim.

## Do not touch
The visual guard (pattern source), semver enforcement in
release tooling (F221 later), fence semantics. Suggested
tests: tests/verification/test_api_compat.py.
