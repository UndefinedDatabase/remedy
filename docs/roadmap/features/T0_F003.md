# T0_F003 — Echte Token-/Kostenmessung (actual_available=true)
**Tier 0 · Abhängigkeiten: keine · Blockiert: F011? nein — F022, F103–F116, F142, KPI M7**

## Ziel & Done
Jeder Provider-Call liefert echte usage/Kosten aus `claude -p --output-format json`.
Done: token_truth zeigt actual_available=true, confidence=high; Jobsumme == CLI-Summen.

## IST-Bezug
- `token_truth.py`: heute character_heuristic, confidence=low („Actual token usage
  is UNAVAILABLE from claude-cli" — stimmt nicht mehr, JSON-Output existiert).
- `pingpong_provider.py` ruft claude-CLI ohne `--output-format` auf.
- token_accounting.json je Task; token_economy.py schätzt nur.

## Design
Neues Modul `packages/orchestration/token_actuals.py`:
```python
@dataclass
class UsageActuals:
    input_tokens:int; output_tokens:int; cache_read:int; cache_creation:int
    total_cost_usd:float; num_turns:int; duration_ms:int; session_id:str
def parse_cli_result(stdout:str) -> UsageActuals | None  # tolerant, None => Fallback Heuristik
```
- pingpong_provider: `--output-format json` als Default; bei Parse-Fehler Fallback auf
  Heuristik MIT Ehrlichkeits-Flag (actual_available=false, reason=parse_failed).
- token_accounting.json erhält `actuals{}`-Block; token_truth aggregiert actuals bevorzugt.
- `session_id` wird persistiert (Grundlage F106 Resume).
