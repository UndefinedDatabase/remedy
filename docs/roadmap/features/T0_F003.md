## Goal & Done
See ROADMAP.md F003; the Done criterion there is binding.

## Context (existing code & prior features)
token_truth.py uses a character heuristic with confidence=low; the provider calls the CLI without --output-format json although real usage data is available there.

## Design
`packages/orchestration/token_actuals.py`:
```python
@dataclass
class UsageActuals:
    input_tokens:int; output_tokens:int; cache_read:int; cache_creation:int
    total_cost_usd:float; num_turns:int; duration_ms:int; session_id:str
def parse_cli_result(stdout:str) -> UsageActuals | None   # tolerant; None => heuristic fallback
```
Provider default becomes JSON output; parse failure falls back to the heuristic WITH the honesty flag (actual_available=false, reason=parse_failed). token_accounting.json gains an actuals block; token_truth prefers actuals. session_id is persisted (foundation for F106).

## Acceptance & tests
Fixture parsing exact; broken JSON -> fallback + flag; measurement_confidence=high only when ALL tasks have actuals; a P6 test asserts nothing estimated is labeled actual.

## Risks / anti-goals
