# T8_F160 — Cross-vendor failover v2
**Tier 8 · Depends on: F058, F156 · Blocks/used by: durability in continuous operation**

## Goal & Done
See ROADMAP.md F160; the Done criterion there is binding.

## Context (existing code & prior features)
F058 chains models within the Claude path; triggers and evidence fields exist.

## Design
failover.py extended: chains as adapter.model tuples across vendor boundaries; preconditions per link: a valid class certificate (F156) + capability coverage (F157, else skip with a note); a health mini-probe (10 s) before takeover; a mandatory report block: chain, reason, cost delta (F158).

## Task slicing
T001 chain resolution + certificate/capability filters + probe + per-link outage tests. T002 report block + the SSE event worker.failover.

## Acceptance & tests
A simulated vendor outage: the job ends green via link 2, fully documented; an uncertified link is skipped (test); quality problems still NEVER trigger failover (the F058 negative test stays).

## Risks / anti-goals
No automatic back-migration mid-job (max one switch per task); chain upkeep belongs to the operator.
