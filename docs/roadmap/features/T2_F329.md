## Goal & Done
Remedy's own test run for a job narrows to the changed parts: for pytest the test folder of each source folder the diff touches plus every test file the diff names; for vitest the test files that import a changed file or are named like it. Anything else, or a diff over more than ten source folders, runs the full command. The check's evidence says which selection it made.

## Acceptance
- A diff in `pkg/a.py` with `tests/pkg/` narrows pytest to `tests/pkg` and a named test file.

- The evidence's `selection` sentence names the selection.
