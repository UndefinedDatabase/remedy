with the evidence that discharged it. DONE when every id this feature owns carries a resolution
line with its evidence in `.agent/live_review.md`, or is carried by name to the next paydown
feature in this feature's closure. The soft limit is 8 sessions (amend0911-feedback rule B); at the
limit the feature closes with what it resolved and carries the rest, which is not a split.
