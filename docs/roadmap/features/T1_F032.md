# T1_F032 — Approval mit Dreiklang
**Tier 1 · Abh.: F031**

## Ziel & Done
Jede Freigabe zeigt: Beleg, erwartetes Ergebnis, Downside. Done: kein Approval ohne
die drei Felder.

## Design
- decision_queue-Eintrag-Schema erweitert: `evidence_refs[] (Pfad+Zeile/Artefakt),
  expected_outcome:str, downside:str` — Erzeuger (Planner/Gates/F027-Replan) MÜSSEN
  füllen; Schema-Validierung (F005) erzwingt.
- UI-Karte: drei beschriftete Zeilen (BELEG/ERWARTUNG/RISIKO, Label-Stil CONVENTIONS),
  evidence_refs klickbar → EvidencePanel (F023 L3).

## Task-Schnitt

- T002: Karten-UI.
