## Goal & Done
The tier proves itself as one unattended arc: `remedy do --design
... --yes` runs fidelity loops AS CYCLES under the multi-cycle
executor's budgets and stops, and the final report embeds a
before/after gallery plus the heatmap trajectory — certificate-
ready. DONE when a fixture design mission runs unattended to a
green (or honestly-blocked) terminal with fidelity rounds appearing
as cycle evidence, budgets/stops interrupt fidelity work at the
established safe points, the report's gallery/trajectory renders
from the loop archives (goldens), and the certificate bundle
carries the visual proof within its size rules.

## How it fits (inspect current shape before building)
Deliberately a COMPOSITION feature (no new mechanics): the fidelity
loop already runs bounded rounds with archives; this feature makes
those rounds first-class under the executor — a design-verify cycle
kind whose per-cycle summary carries the round's numbers (the cycle
evidence schema gains the additive fidelity fields), so should_stop,
checkpoints, escalation and reports all apply for free. The report
renderer gains the design section (pure, from archives: round strip
thumbnails, per-pair number trajectory, residue link on abort);
the certificate's size budget handles images via its established
referencing rules (thumbnails inline, full shots by hash+path).

## Design (suggested shape)
- Executor integration: fidelity rounds map onto cycles (one round
  per cycle or batched per config — the loop's counter and the
  executor's counter reconcile: ONE counter owns rounds, the loop's;
  cycles report it — no double bookkeeping, stated).
- Safe points: capture/compare/review are provider-and-tool work
  under the same stop/budget checks (the loop feature promised it;
  this feature proves it under --yes with injected stops mid-round).
- Report: "Design fidelity" section — gallery (round 1 vs final per
  pair, thumbnails), the SSIM/finding-count trajectory chart data
  (numbers table; charting stays the UI's job), links into
  archives; abort → the residue report embedded prominently.
- Certificate: the design section joins the claims (final numbers
  per pair) with thumbnail members; verify cross-checks the claimed
  finals against the archived comparison records.
- The proof run: a documented real design mission (fixture-repo
  scale) executed unattended and archived as the tier's evidence —
  a deliverable, not just tests.

## Task slicing
- **T001** cycle integration + the one-counter rule + additive
  cycle fields + stop/budget-mid-round tests.
- **T002** the report section (pure renderer over archives) +
  goldens (converged, aborted) + certificate claims/cross-checks.
- **T003** the unattended end-to-end on the fixture + the
  documented proof run + docs.

## Acceptance
- Unattended fixture reaches its terminal with fidelity rounds as
  cycles; injected stop mid-round lands at a safe point with a
  resumable state. Report goldens exact both shapes; certificate
  verifies including the visual claims. One round counter (grep +
  reconciliation test). The proof-run artifact exists and verifies.

## Edge cases & assumption defaults (A9)
- Mixed jobs (design + logic tasks): design cycles interleave with
  normal ones per the DAG — nothing special, and the test proves
  it. Budget exhaustion mid-fidelity: the standard stop with the
  round archived partial (honest snapshot).

## Orchestrator brief
Gate on the loop + executor + report + certificate. This is
composition — reject new mechanics on sight. The proof run is a
campaign-style deliverable (run, archive, document), scheduled
last.
