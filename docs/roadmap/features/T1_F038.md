# T1_F038 — Node-Chat (read-only fundiert)
**Tier 1 · Abh.: F023, F004-Traces**

## Ziel & Done
„Warum so gelöst?" — Antworten NUR aus Evidence des Nodes, mit Artefakt-Zitaten.

## Design
- Endpoint via Command? Nein — read-only: `GET /runs/{rid}/explain?q=…` wäre POST-frei,
  aber LLM-Kosten → als Command `explain_run{run_id,question}` (Queue, Ergebnis via SSE
  `artifact.created` type=explanation) — hält Schreibkanal-Regel.
- Prompt: Frage + Prompt-Trace-Auszug + Review + Diff-Stat; Schema Answer{text,
  citations:[{artifact,anchor}]}; Antwort speichert als `explanations/<n>.json`.
- UI: Chat-Tab im EvidencePanel; jede Antwort mit Zitat-Chips (Klick → Artefakt-Anker).
  Ohne Zitat validierbare Aussage → Renderer markiert Absatz „unbelegt" (P6-Sichtbarkeit).

## Task-Schnitt
- T001: Command+Generator+Schema+Zitat-Validierung(Anker existieren)+Tests.
- T002: Chat-UI.

## Akzeptanz & Tests
- Fixture-Fragen → Antworten, deren Zitat-Anker alle auflösen; Halluzinations-Kanarien-
  test (Frage nach nicht existentem Detail → „nicht in der Evidence").
