# T4_F124 — Card hygiene (manual + periodic)
**Tier 4 · Depends on: F117, F113, F045 · Blocks/used by: collection quality**

## Goal & Done
See ROADMAP.md F124; the Done criterion there is binding.

## Context (existing code & prior features)
Collections rot without curation - but deletion is dangerous.

## Design
`remedy memory compact`: merge proposals for near-duplicates (similarity heuristic), archive (never delete), budget check, conflict -> decision. Plus a periodic LLM-assisted cleanup loop (cheap model): checks active cards against current code (do referenced paths/patterns still exist?) and files archive/update PROPOSALS.

## Task slicing
T001 compact + merge heuristic + tests. T002 cleanup loop + proposal path + obsolete-card fixture.

## Acceptance & tests
The obsolete fixture card gets an archive PROPOSAL, not removal; merges keep both originals archived.

## Risks / anti-goals
No silent deletion, ever; the loop writes proposals only.
