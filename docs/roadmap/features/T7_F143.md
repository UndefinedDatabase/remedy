# T7_F143 — Genesis run: one prompt -> one product
**Tier 7 · Depends on: everything above · Blocks/used by: M8; the flagship**

## Goal & Done
The flagship proof, by composition only (A6): an empty folder →
scaffold (the stack choice recorded as an ADR) → a mission through
the compiler and orchestrator loop → multi-cycle until DoD green
plus product smoke → certificate, tour and story. One prompt in,
one verifiable product out — and a DOCUMENTED REAL PROOF RUN is
the deliverable, archived with everything a skeptic needs. DONE
when the genesis path runs unattended on the fixture prompt to a
certified terminal, the scaffold step's stack choice lands as a
confirmed-path ADR draft with its reasoning evidence, every
composed stage is the existing feature (a new-mechanics diff is
the reject condition), the proof run's artifacts (certificate,
story export, scoreboard-grade numbers) verify end to end, and
the runbook documents reproduction.

## How it fits (composition inventory — the feature IS this list)
`remedy genesis "<prompt>"` sequences: init (F081, non-git empty
dir → git init here IS user-consented by the genesis contract —
the one documented exception to init's rule, stated loudly) →
intake/mission compile (F013/F069) with the scaffold milestone

product smoke (F062) gates → terminal → certificate (F060) +
tour (F036) + story export (F039). Budgets, fences, autonomy
level and the permission matrix all bind — genesis is a caller,
never an exception (except the ONE documented git-init line).

## Design (suggested shape)
- `genesis` as a thin CLI composition (a mission template + the
  sequencing described — audit every step's verb against the
  inventory; the module should read like a table of calls).
- The stack-choice moment: clarification item (options from a
  small curated stack menu per product shape, default from
  config) + the ADR draft with the planner's rationale as
  Context — two artifacts, one decision, zero new machinery.
- The empty-folder exception: `--here` on an empty dir runs git
  init with the explicit output line ("genesis initialized git —
  the one setup action it performs"); non-empty dirs refuse
  toward normal init/do (safety).
- The proof run: a real product prompt (fixture-honest scale: a
  small complete web tool), run unattended, archived under a
  genesis-proof area with the runbook (command, config, versions,
  costs), the certificate verified, the story exported — the M8
  gate artifact.
- Failure honesty: a genesis that blocks produces the same
  artifacts about its blocked state (the certificate-of-failure
  stance) — the flagship proves the SYSTEM, including its
  honesty.

## Task slicing

## Acceptance
- Fixture genesis: empty dir → certified green with all three
  end artifacts verifying; the ADR draft exists with rationale;
  the exception line printed exactly once. No new mechanics
  (grep + review). Blocked-genesis fixture produces honest
  artifacts. The proof-run archive + runbook exist and a clean
  environment reproduces the fixture path.

## Edge cases & assumption defaults (A9)
- Prompts implying stacks outside the menu: the clarification
  carries a free-slot option requiring attended mode (unattended
  sticks to the menu — bounded autonomy, stated). Genesis under
  L2: every gate asks as L2 demands — genesis composes, levels
  rule (the test proves the asks appear).
