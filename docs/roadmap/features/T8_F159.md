# T8_F159 — Cross-vendor benchmark & scoreboard
**Tier 8 · Depends on: F156, F132, F082 · Blocks/used by: the sales artifact; F210, F232**

## Goal & Done
"Which worker for which work" becomes a published table with
receipts: the scoreboard runs the bench order set (plus optionally
the review-tournament diffs) over ALL certified adapters and
renders a matrix per task class — pass rate, normalized cost, wall
time, repair rounds, format errors — where EVERY cell links its
individual runs' evidence; exported as markdown + JSON, with a
publication variant stripping repo internals. DONE when the
scoreboard runs certified-only (uncertified adapters listed as
not-certified, never silently skipped), cells match the underlying
run records (the consumers-loop discipline), normalized costs carry
bases and group by them, the publication redaction provably strips
the internal-path/name classes (a redaction test corpus), and cost
preview gates the run (it is the tier's most expensive command).

## How it fits (composition on the shared runner — inspect first)
The tournament feature noted the kinship: ONE runner core (frozen
set × candidates × recorded metrics × history) with two fronts —
this feature's front runs bench ORDERS across ADAPTERS (the bench
harness parameterized by adapter, which certification's mini-
gauntlet already exercised — verify the factoring landed; if the
gauntlet/bench/certify trio grew divergent runners, the
consolidation order comes first). Certification gates entry
(certificate validity per adapter, the router's rules reused);
pricing supplies normalized costs; the matrix/evidence-links
pattern follows the gauntlet's matrix report. The publication
variant reuses the redaction denylist discipline extended with a
repo-internals class (paths, project names, evidence URLs →
placeholders) — the redaction corpus is the deliverable (F249's
later pattern seeded here, noted).

## Design (suggested shape)
- `packages/workers/scoreboard.py`: run(adapters=certified) →
  per (adapter, class): {pass_rate, cost {value, basis, currency},
  wall, repair_rounds, format_errors, n, run_refs[]} → history
  (series-versioned like bench) + the reports.
- Rendering: worker_scoreboard.md (the matrix, per-cell run links,
  the basis/series/date header, not-certified rows with the
  certify hint) + JSON; `remedy worker scoreboard [--adapters]
  [--include-reviews]` (the tournament diffs as an optional
  reviewer section, its runner reused).
- Publication: `--publish-variant` → the redacted copy (corpus-
  tested: internal paths, slugs, URLs, hostnames replaced;
  numbers and structure intact) + the provenance line (suite
  versions, date, bases).
- Cost preview mandatory (the expensive-command registry).

## Task slicing
- **T001** the runner-factoring verification/consolidation + the
  certified-only gating + scripted-fake matrix goldens.
- **T002** rendering (md/json, links, not-certified rows) + the
  consumers-loop test (cells vs run records) + history.
- **T003** the publication redaction (corpus + tests) + the
  reviewer section option + cost preview + the marker-gated real
  run path + docs.

## Acceptance
- Certified-only enforced (uncertified rendered as such); cells
  equal run records (loop test); bases grouped, never blended.
  Redaction corpus fully neutralized with structure intact
  (before/after goldens). Preview gates. History series rules
  hold (order-set changes reset).

## Edge cases & assumption defaults (A9)
- Adapters certified for SOME classes: cells outside
  classes_passed render not-certified-for-class (per-cell
  honesty, not per-adapter). Local adapters' zero-basis costs:
  their column notes the basis prominently (a free-looking
  column needs its asterisk).

## Orchestrator brief
T001's factoring check protects three features — findings first.
The per-cell honesty rules and the redaction corpus go verbatim.
Real runs are campaign deliverables, marker-gated.

## Do not touch
Bench orders, certification bars, tournament truth sets, pricing
math. Suggested tests: tests/workers/test_scoreboard.py.
