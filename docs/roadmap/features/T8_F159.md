## Design
packages/workers/scoreboard.py: runs the F082 set (+optional F132 review diffs) over all certified adapters; a matrix per task class: pass_rate, cost_eur (F158-normalized), wall_time, repair_rounds, format_errors; export worker_scoreboard.md + JSON; EVERY cell links its individual runs (evidence paths). CLI `remedy worker scoreboard [--adapters]`. A publication variant strips repo internals (F249 redaction pattern).

## Task slicing
T001 runner + matrix + linking + tests (2 fake adapters with known deltas). T002 renderers + the publication variant + a docs-gallery slot (F217 later).

## Acceptance & tests
The scoreboard reproduces; every number is clickable down to a run; the publication variant passes the redaction corpus.

## Risks / anti-goals
Never smooth numbers or silently drop outliers - exclusions only with a visible note + reason.
