## Goal & Done
See ROADMAP.md F236; the Done criterion there is binding.

## Context (existing code & prior features)
F004 delivers run events incl. token deltas; F021 humanizes - the RAW view is missing. Redaction gates exist.

## Design
An optional L2/L3 tab 'live' (visible only while a run is active): the rendered token/tool stream from run events (an SSE sub-selection ?run=rid), throttled at 10 Hz with batch appends (no react state storm: a ref buffer + rAF flush), auto-scroll with stop-on-user-scroll. EVERY fragment passes the server-side F171 redaction and the F174 class filter BEFORE it reaches the stream (one filter point in the event stream, not in the client). Afterglow: after run end the tab shows the last n KB with a link to the full trace (L3).

## Task slicing
T001 the server filter point + the sub-stream + tests (a canary corpus over the stream). T002 the UI tab + throttle/buffer + a playwright latency assertion (<1 s) + the afterglow view.

## Acceptance & tests
The latency assertion holds; canaries never appear (the corpus runs in CI); a 100 Hz fixture renders fluidly (fps measured with the F044 harness); the tab degrades cleanly to afterglow at run end.

## Risks / anti-goals
No input channel in this tab (steering stays the F030 field); the raw stream is display - evidence stays the truth (a note line says so).
