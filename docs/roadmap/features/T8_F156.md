# T8_F156 — Worker certification suite
**Tier 8 · Depends on: F151, F152, F082 · Blocks/used by: routing gates, F159, F232**

## Goal & Done
See ROADMAP.md F156; the Done criterion there is binding.

## Context (existing code & prior features)
The F082 harness (5 frozen orders) and F005 format discipline are the base.

## Design
packages/workers/certify.py + `remedy worker certify <adapter>`: stages (1) capability probe (declared vs. real, mini-calls per capability), (2) format discipline (20 schema answers, error rate), (3) mini-gauntlet (F082 orders S-M), (4) isolation check (F152 A/B). Output ~/.remedy/workers/<adapter>/worker_certificate.json {adapter, version, cli_version, suite_v, date, capabilities_verified, format_error_rate, classes_passed, cost_basis, isolation_ok} - signable from F165. The router reads classes_passed as a hard gate.

## Task slicing
T001 probe + format stage + certificate format + tests. T002 gauntlet integration + router enforcement + `remedy worker list` shows certification state.

## Acceptance & tests
Certification reproduces (a second run yields equal classes_passed on a deterministic fake worker); uncertified classes provably locked in the router; an outdated suite version warns.

## Risks / anti-goals
Freeze suite orders like F082 (versioned); a certificate is a snapshot - expiry hints after adapter/CLI version changes, no eternal validity.
