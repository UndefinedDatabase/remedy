## Goal & Done
See ROADMAP.md F241; the Done criterion there is binding.

## Context (existing code & prior features)
F039 exports stories as standalone HTML; F024 autoplays the scrub; playwright video capture exists in the toolchain.

## Design
`remedy jobs story <id> --video [--max-seconds 120]`: headless playwright drives the story autoplay in the demo-deterministic mode (the F012/F084 mechanics: a frozen clock, a fixed 1280x720 viewport), chapter narration cards overlaid (the existing story UI), captured as webm with an optional mp4 transcode when ffmpeg is present (else an honest note). Chapter marks ship as a companion .vtt. Pacing: a seq time-lapse with chapter pauses (readable), kept under max-seconds by adaptive compression - and the closing frame ALWAYS states 'time-lapse; real duration: X' (honesty end card, renderer-enforced).

## Task slicing
T001 the deterministic capture harness + webm + tests (existence, duration tolerance, frame-count band). T002 chapter timing + vtt + the honesty end card + the mp4 path + a fixture golden (first/last frames pixel-compared, F091 tolerance).

## Acceptance & tests
The fixture video is <2 min, playable, with a synchronized vtt (spot checks); the end card names the real duration; a second export reproduces within the frame tolerance band.

## Risks / anti-goals
No video editor (one template, done well); the real run duration is never obscured (the end card is mandatory).
