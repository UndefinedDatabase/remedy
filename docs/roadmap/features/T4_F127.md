# T4_F127 — Optional retrieval above threshold
**Tier 4 · Depends on: F118 · Blocks/used by: scale**

## Goal & Done
See ROADMAP.md F127; the Done criterion there is binding.

## Context (existing code & prior features)
Hundreds of cards outgrow pure rules - but small collections must stay bit-identical.

## Design
Only above 200 active cards: a local embedding index (sentence-transformers or provider embeddings per config) as a PRE-filter (top-50) before the deterministic F118 ranking; below the threshold the path is bit-identical to F118.

## Task slicing
T001 index + prefilter + threshold switch + tests.

## Acceptance & tests
Regression proves identity below; same top-k above at 10x speed on a synthetic 500-card set.

## Risks / anti-goals
The prefilter must never override scope/status rules.
