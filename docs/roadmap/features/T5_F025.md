## Context (existing code & prior features)

## Design
pause_job/resume_job + node-level pause via the context menu: pause takes effect before the next provider call (running calls finish); session ids persist (F003) so resume continues exactly; paused nodes show the state visually.

## Task slicing

## Acceptance & tests
Pause+resume equals an uninterrupted run (deterministic comparison); node pause blocks only its subtree.

## Risks / anti-goals
