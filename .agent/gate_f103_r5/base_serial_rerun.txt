=== EVIDENCE 0 — why apps/ui parity by COPY is not enough ===================
_frontend_is_stale() (packages/orchestration/ui_server.py:2748) compares the
MTIME of apps/ui/dist/index.html against every file under apps/ui/src/.
git worktree add writes the source tree with mtime = checkout time, while
cp -a PRESERVES the copied dist mtimes. So in a fresh base worktree src is
always newer than dist -> stale -> _auto_build_frontend() -> suppressed by
REMEDY_UI_NO_AUTO_BUILD=1 -> returns None -> 'ERROR: React UI not built.'
-> sys.exit(1). Content parity is intact; only the timestamps differ.
