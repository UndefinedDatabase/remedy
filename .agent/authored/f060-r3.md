### C3 — `F060 R3 C3: the certificate verifier and its verdict (T002)`
Paths: `packages/orchestration/job_certificate_verify.py` (NEW FILE),
`tests/test_no_orphan_modules.py`.
1. A two-paragraph docstring (what it checks, integrity first and claims second, DECISION F060 D3;
   that it needs no data folder and no checkout, and that a certificate is not a signature). A WHY
   comment above each public definition. It imports `job_certificate`, `job_certificate_claims`,
   `CERTIFICATE_TERMINAL_STATES` from `job_certificate_sources`, `verify_review_zip` from
   `review_zip` and `MAX_GENERATED_MEMBER_BYTES` from `archive_plan`, at the top. No blind
   `except Exception`.
2. Public names:
   - `CertificateVerification`, a frozen dataclass: `ok: bool`, `problems: tuple[str, ...]`,
     `manifest: dict | None` (None when no manifest could be read).
   - `verify_job_certificate(bundle_path: str | Path) -> CertificateVerification`, in this order,
     every check appending a sentence to `problems` and `ok` being `not problems`:
     (a) Not a ZIP (`zipfile.is_zipfile` false, or a missing file): exactly
         `f"{bundle_path} is not a ZIP archive."`, and stop. No `manifest.json` member: exactly
         `"The bundle holds no manifest.json."`, and stop. A `manifest.json` larger than
         `MAX_GENERATED_MEMBER_BYTES` by its header: refused before reading, and stop. Bytes that
         are not a UTF-8 JSON object: exactly `"manifest.json is not a JSON object."`, and stop.
     (b) The manifest: `bundle_v` not 1 → `f"manifest.json names bundle_v {v!r}; this Remedy reads bundle_v 1."`;
         `kind` not `CERTIFICATE_KIND` → `f"manifest.json names kind {k!r}, not {CERTIFICATE_KIND}."`;
         a `signature` that is not None →
         `"manifest.json carries a signature, which version 1 reserves and leaves empty."`; each
         missing key of DECISION F060 D1 (2) → `f"manifest.json lacks the key {key!r}."`; a
         `members` or `referenced` entry that is not an object with a string `path`, a `class` in
         `CERTIFICATE_MEMBER_CLASSES`, a 64-character lower-case hex `sha256` and a non-negative
         int `size` (and, for `referenced`, a string `obtain`) →
         `f"manifest.json {field} entry {index} is malformed."`; a referenced class outside
         `CERTIFICATE_REFERENCED_CLASSES` →
         `f"Referenced member {path!r} is of class {cls!r}, which a certificate always embeds."`.
         Any problem so far: stop.
     (c) The model: each `members` entry as `{"kind": "regular", "mode": CERTIFICATE_MEMBER_MODE,
         "sha256": ..., "size": ...}`, and `manifest.json` itself with the sha256 and size of the
         bytes read in (a); every sentence of `verify_review_zip(bundle_path, {"model": model})`
         is a problem. The embedded sizes adding up to more than `size_budget_bytes` →
         `f"The embedded members hold {total} bytes, more than the manifest's budget of {budget} bytes."`.
         Any problem so far: stop.
     (d) The claims: a key set other than `CERTIFICATE_CLAIM_KEYS` →
         `f"The claims carry the keys {sorted(keys)}, not {sorted(CERTIFICATE_CLAIM_KEYS)}."`, and
         stop. `terminal_state` outside `CERTIFICATE_TERMINAL_STATES` →
         `f"The claimed terminal state {state!r} is not a state in which a job has ended."`. The
         first member of class `report`: none → `"The bundle holds no report to check the claimed terminal state against."`;
         one whose text lacks the whole line `f"- State: {state}"` →
         `f"Member {path}: its State line does not name the claimed terminal state {state}."`.
         Then for each pair (member path, claim key, derived value) — (`token/budget_actuals.json`,
         `cost`, the first of `cost_claims_from_member`), (the same, `cost_basis`, the second),
         (`verdicts/dod_result.json`, `dod_summary`, `dod_summary_from_member`),
         (`verdicts/final_verifier_report.json`, `regression_status`,
         `regression_status_from_member`), the function applied to the member's bytes read from
         the ZIP, or to None when no such member is embedded — a derived value unequal to the claim →
         `f"Member {path} ({'present' if present else 'absent'}) gives the {key} {derived!r}, but the claims say {claimed!r}."`.
         `decisions_count` that is not an int (a bool is not one) of zero or more →
         `f"The claimed decisions count {value!r} is not a whole number of zero or more."`.
   - `render_certificate_verdict(verification: CertificateVerification) -> str`, the lines joined
     by `"\n"` with a final newline:
     1. `f"Run ended: {terminal_state}"`, or, with no manifest,
        `"Run ended: unknown — the certificate's manifest could not be read."`;
     2. with a manifest: `f"Job {job} of project {project or '(none)'}, certificate issue {issue}, created {created}."`,
        then `f"Claims: Definition of Done {dod}; cost {cost} (basis: {basis}); decisions {count}; regression status {regression}."`
        — `dod` is `"not recorded"` for None, else `f"{passed_count} of {check_count} checks passed, released {'yes' if released else 'no'}"`;
        `cost` and `regression` `"not recorded"` for None; `basis` the list joined by `", "`, or
        `"none"` — then `f"Members: {m} embedded, {r} referenced."`. A claim value of an
        unexpected shape is shown with `repr`, never raised on;
     3. ok: `"Certificate: intact — every member matches its hash and every claim agrees with its member."`;
        otherwise `f"Certificate: NOT INTACT — {n} problem(s):"` and one line `f"  - {problem}"`
        per problem;
     4. last, `CERTIFICATE_NOT_A_SIGNATURE`.
3. `tests/test_no_orphan_modules.py`: the sources module is now reached by the verifier, so its
   entry is REPLACED, in the same sorted position, by `("packages/orchestration/job_certificate_verify.py",`

### C4 — `F060 R3 C4: the tamper matrix and the claim checks of the certificate verifier`
Path: `tests/orchestration/test_job_certificate_verify.py` (NEW FILE). A fixture builds, with
`build_job_certificate`, a certificate holding one member of each of the seven classes, whose
claims are derived by the three functions of C2 from its own members and whose report holds
`- State: completed`. A helper rewrites a copy of a certificate member by member with the review
package's member metadata (fixed timestamp, Unix mode bits 0o644, deflate), so a test can change,
remove or add one member, or rewrite the manifest. Tests:
(a) the fixture verifies with no problem, and `render_certificate_verdict` equals the test's own
    literal text;
(b) a failed job's certificate made through `collect_certificate_inputs` verifies, and its verdict's
    first line is `Run ended: failed`;
(c) the tamper matrix, parametrized by member class with readable ids, plus one case for the
    manifest: one member's bytes changed while the manifest stays → not ok, a problem names that
    member's path; a member removed and an unlisted member added → each named;
(d) a doctored report (its State line changed, its `sha256` and `size` rewritten in the manifest)
    and a doctored cost (the actuals' cost changed the same way) → the integrity check passes and a
    claim problem names `report.md` or `token/budget_actuals.json`;
(e) the claims rewritten in the manifest: `dod_summary`, `regression_status`, `cost_basis`, a key
    removed, `terminal_state` `running`, `decisions_count` -1 and `True` → each problem exactly;
(f) the manifest refusals of (a) and (b), one parametrized case each: not a ZIP, a missing file,
    no manifest, not a JSON object, `bundle_v` 2, another `kind`, a signature, a missing key, a
    malformed member entry, a referenced `report`, and a budget smaller than the embedded sizes;
(g) a broken certificate's verdict: first line `Run ended: ...`, the `NOT INTACT` line with the
    count, every problem on its own line, and `CERTIFICATE_NOT_A_SIGNATURE` last.
