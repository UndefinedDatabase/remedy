### C3 — `F141 R2 C3: a job keeps the level of its first context, and the read seam (DECISION F141 D2)`
Paths: `packages/orchestration/permission_matrix.py`, `packages/orchestration/builder_context.py`,

2. `permission_matrix.py` gains, with a one-line WHY comment above each:
   - `JOB_LEVEL_FILENAME = "autonomy_level.json"`, kept in `job_dir(job_id, root)`.
   - `pinned_job_level(job_id: str | None, *, root: Path | None = None) -> str`: an empty or None
     `job_id`, or no file, answers `AUTONOMY_DEFAULT_LEVEL` and reads nothing else; a file whose text
     is not a JSON object whose `level` is in `AUTONOMY_LEVELS` raises `AutonomyConfigError` with
     exactly `f"The level recorded for job {job_id} in {path} is not one of L2, L3, L4 or L5."`;
     otherwise its `level`.
   - `pin_job_level(job_id: str | None, *, config: RemedyConfig | None = None, root: Path | None = None, now: datetime | None = None) -> str`:
     an empty or None `job_id` answers `AUTONOMY_DEFAULT_LEVEL`, reading and writing nothing; an
     existing file answers `pinned_job_level`; otherwise the policy is
     `load_autonomy_policy(config, root=root, record=False)` (imported inside the function), and when
     `job_dir(job_id, root)` is not a folder its `level` is answered and nothing is written; else one
     file is written atomically (a temporary file in the same folder, then `os.replace`) holding
     `json.dumps` of exactly `level`, `pinned_at` (ISO time of `now`, default the current UTC time)
     and `config_path` (the policy's), and the level is answered. `root` defaults to
     `resolve_data_root()` wherever it is read.
3. `build_builder_context` gains the keyword parameter `job_id: str = ""` after
   `context_record_dir`, and before anything else in its body it calls
   `require_permission("read", PermissionRequest(level=pin_job_level(job_id), subject=..., job_id=job_id or None))`,
   `subject` being `f"the builder's context of job {job_id}"` for a job and `"the builder's context"`
