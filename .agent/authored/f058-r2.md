### C4 — `F058 R2 C4: the failover walk wraps a role's provider where a run builds it (T002, DECISION F058 D2)`
Paths: `packages/orchestration/model_failover.py`, `packages/orchestration/role_provider_factory.py`,
`tests/test_no_orphan_modules.py`, `tests/orchestration/import_reachability_allowlist.txt`.
- `model_failover.py` gains, each public name with a one-line WHY comment above it, and the module
  docstring's Public API list naming each: imports of the four predicates named in the Bundle.
  - `FAILOVER_REASON_PROVIDER_UNAVAILABLE: str = "failover:provider_unavailable"`.
  - `is_failover_trigger(out: Any) -> bool`: `error = getattr(out, "error", "") or ""`; False when
    `error` is empty, when `getattr(out, "error_class", "") == "parse"`, when `error` starts with
    `"malformed_output:"`, or when `is_timeout_error`, `is_nonzero_exit_error` or
    `is_rate_limit_error` answers True for it; otherwise
    `is_provider_unavailable_error(error) or is_provider_connection_error(error)`.
  - `@dataclass(frozen=True) class FailoverLinkAttempt`: `position: int`, `provider: str`,
    `model: str`, `error: str`; `to_json()` returning `{"position", "provider", "model",
    "error"}` with those values.
  - `@dataclass(frozen=True) class FailoverDisclosure`: `role: str`, `intended_provider: str`,
    `intended_model: str`, `primary_error: str`, `attempts: tuple[FailoverLinkAttempt, ...]`,
    `used: FailoverLinkAttempt | None`, `reason: str = FAILOVER_REASON_PROVIDER_UNAVAILABLE`;
    `to_json()` returning `{"reason": ..., "role": ..., "intended": {"provider": ..., "model":
    ...}, "used": used.to_json() or None, "primary_error": ..., "attempts": [a.to_json() ...]}`.
  - `class FailoverProvider`: `__init__(self, primary: Any, *, role: str, intended_provider: str,
    intended_model: str, links: tuple[FailoverLink, ...], build_link: Callable[[FailoverLink],
    Any])`; read-only properties `primary`, `links`, `build_link`, `name` (the primary's `name`) and
    `supports_resume` (`bool(getattr(primary, "supports_resume", False))`); `__getattr__` hands
    any other attribute to the primary and raises `AttributeError` for a name starting with `_`;
    `build(prompt, *, timeout_sec=120, max_output_chars=50000, resume=None)` and `review(...)` of
    the same signature both go through one private walk: call the primary's method with the
    arguments as given; when `is_failover_trigger(out)` is False return `out` unchanged and build
    no link; otherwise for each link in order, at its 1-based position: build it with
    `build_link(link)` (a `RuntimeError` records an attempt whose error is
    `f"provider_error: {type(exc).__name__}: {exc}"` and goes on to the next link), call its method
    with the same prompt, `timeout_sec` and `max_output_chars` and `resume=None`, and record a
    `FailoverLinkAttempt` with the output's `error` (or `""`); the first output whose
    `is_failover_trigger` is False is returned with the attribute `failover_disclosure` set to a
    `FailoverDisclosure` whose `primary_error` is the primary output's `error`, whose `attempts`
    are every attempt so far and whose `used` is that link's attempt. When every link has been
    tried, the PRIMARY's output is returned, with `failover_disclosure` naming every attempt and
    `used=None`.
- `role_provider_factory.py`: `create_role_provider` gains a last keyword `with_failover: bool =
  True` (its docstring says what it does). It builds the provider exactly as before; then, when
  `with_failover` is True and `resolve_failover_chains().get(role, ())` is not empty, it returns

  model=link.model, stream_evidence=stream_evidence, stream_evidence_dir=stream_evidence_dir,
  make_provider=make_provider, with_failover=False)`; otherwise it returns the provider itself.
