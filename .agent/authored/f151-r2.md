### C3 — `F151 R2 C3: the conformance kit and its broken toys`
Paths: `packages/contracts/adapter_conformance_kit.py` (NEW FILE),
`tests/contracts/test_adapter_conformance_kit.py` (NEW FILE), `tests/test_no_orphan_modules.py`.
If this commit would reach 500 insertions, split it once into `C3a` (module and orphan entry) and
`C3b` (tests) and say so in the handback. The module:
- `CONFORMANCE_DIMENSIONS = ("capabilities", "invocation", "stream", "usage", "errors",
  "isolation", "transport")`; frozen `ConformanceFailure(dimension: str, detail: str)`; frozen
  `ErrorSample(error_text: str, exit_code: int | None, expected: FailureClass)`; frozen
  `AdapterSamples(model: str, stream_lines: tuple[str, ...], expected_stream_events: tuple[dict, ...],
  usage_raw: str, expected_usage: AdapterUsage | None, error_samples: tuple[ErrorSample, ...])`;
  `CANONICAL_PROMPT_PARTS`, a tuple of three short ASCII sentences without quotes or newlines.
- `check_conformance_dimension(adapter, samples, dimension)` returns a tuple of failures, empty when
  the dimension conforms, and raises `ValueError` for a name outside `CONFORMANCE_DIMENSIONS`;
  `run_adapter_conformance(adapter, samples)` concatenates every dimension's, in order. A first
  check in every dimension: the adapter is an instance of `WorkerAdapter`. The kit catches no
  exception except the `ValueError` the invocation check expects, so an adapter that raises
  elsewhere fails its test loudly (the `BLE001` ratchet allows no blind handler).
- `capabilities`: `adapter_id` matches `^[a-z][a-z0-9-]*$`; `capabilities(model)` is an
  `AdapterCapabilities` whose five flags are exactly `bool` and whose `max_context_tokens` is an
  `int`, not a `bool`, and at least 0; two calls are equal.
- `invocation`: for each role of `ADAPTER_ROLES`, `build_invocation(role, CANONICAL_PROMPT_PARTS,
  InvocationOptions(model=samples.model))` is a `CliInvocation` with a non-empty `argv` of strings
  whose first element is non-empty, or an `HttpInvocation` with `method` `GET` or `POST`, a `url`
  beginning `http://` or `https://` and a `dict` body; every prompt part occurs in the carried text
  (`"\n".join(argv) + "\n" + stdin_text`, or `json.dumps(body, sort_keys=True)`); a second call is
  equal; and `build_invocation("planner", ...)` raises `ValueError`.
- `stream`: `map_stream(samples.stream_lines)` is a tuple; when `streaming` is false it is empty;
  when true, `stream_lines` is non-empty, every event is a `dict` whose `event_type` is in
  `STREAM_EVENT_TYPES`, and the tuple equals `expected_stream_events`.
- `usage`: `map_usage(samples.usage_raw) == samples.expected_usage`; a non-`None` answer is an
  `AdapterUsage` whose `actuals` is a `UsageActuals` and whose `raw_counters` is a non-empty `dict`;
  `map_usage("")` is `None`.
- `errors`: the samples hold an expected `PROVIDER_UNAVAILABLE` and an expected `PROVIDER_TIMEOUT`;
  every sample's `classify_error(error_text, exit_code)` is in `ADAPTER_ERROR_CLASSES` and equals
  its `expected`.
- `isolation`: `isolation()` is `None`.
- `transport`: `ast.parse(textwrap.dedent(inspect.getsource(type(adapter))))`; a failure for every
  `Name` id, `Attribute` attr, `arg`, function name and imported alias whose lower-cased text
  contains `retry`, `retries`, `timeout`, `sleep` or `backoff`, and for every `Name` or import whose
  root is one of `subprocess`, `socket`, `urllib`, `http`, `requests`, `httpx`, `anthropic`,
  `ollama`, `asyncio`, `time`.
The tests: a conforming CLI toy and a conforming HTTP toy each read `()` from
`run_adapter_conformance`; one broken toy per dimension, each a small subclass or variant of the
conforming toy, is parametrized and its failures' dimensions equal exactly `{that dimension}`
(capabilities: a non-`bool` flag; invocation: a dropped prompt part, and separately a role accepted
that should raise; stream: a non-streaming toy that returns events, and separately an event type
outside the set; usage: an answer for empty raw output; errors: a timeout classified as unavailable;
isolation: a non-`None` declaration; transport: a toy whose method loops over attempts and one that
names `subprocess`); samples lacking a timeout sample fail `errors` for the conforming toy;
`check_conformance_dimension` raises `ValueError` for `"bogus"`; `CONFORMANCE_DIMENSIONS` is
exactly that tuple. In `tests/test_no_orphan_modules.py` add to `ALLOWED_UNWIRED`, in path order:
`("packages/contracts/adapter_conformance_kit.py", "F151's conformance kit; every adapter's tests
import it and no product path does, by design (DECISION F151 D2)")`.
