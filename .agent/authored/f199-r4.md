  F199 D1 and saying: a report is written only on this machine, under the data root, and Remedy
  never sends it anywhere; writing one never raises, so a crash report cannot hide the error it
  records. `from __future__ import annotations`; only `packages.` and standard-library imports;
  only named exception classes caught. Public names, each with a one-line WHY comment above it:
  - `CRASH_RECENT_DAYS: int = 7`;
    `CRASH_NOTICE: str = "This report stays on this machine. Remedy never sends it anywhere."`
  - `crash_reports_dir(root: Path | None = None) -> Path` — `data_class_dir("crash", root)`,
    the class name written as that literal, because `tests/test_data_root_classes.py` finds a
    created class only from a literal first argument of `data_class_dir`.
  - `remedy_version() -> str` — `importlib.metadata.distribution("remedy").version`, `"dev"` on
    `PackageNotFoundError`.
  - `config_digest() -> str` — `"sha256:" + sha256(json.dumps(_config_snapshot(),
    sort_keys=True, default=str))` with `_config_snapshot` imported inside the body from
    `run_manifest`; an `OSError` or a `ValueError` gives `"unavailable"`.
  - `render_crash_report(error: BaseException, *, command: str, when: datetime, version: str,
    digest: str) -> str` — exactly these lines: `# Remedy crash report`, a blank line,
    `- time: <when as ISO 8601 UTC, seconds, ending Z>`, `- version: <version>`, `- command:
    <command>`, `- error: <type name>: <message>`, `- configuration digest: <digest>`, a blank
    line, `## Traceback`, a blank line, a fence of three backticks, the traceback of
    `traceback.format_exception(type(error), error, error.__traceback__)` joined and stripped of
    trailing newlines, a closing fence, a blank line, `CRASH_NOTICE`, and a final newline. The
    whole text passes through `redact_text` (`stream_evidence`) and then `home_relative_text`
    (`self_health`).
  - `write_crash_report(error: BaseException, *, command: str, root: Path | None = None, now:
    datetime | None = None) -> Path | None` — `now` defaults to `datetime.now(timezone.utc)`; the
    file is `crash_reports_dir(root) / f"{now:%Y%m%dT%H%M%S%f}Z-{os.getpid()}.md"`, the folder made
    with mode `0o700`, the file created with `os.open(..., os.O_WRONLY | os.O_CREAT | os.O_EXCL,
    0o600)` and written UTF-8; an `OSError`, a `ValueError` or a `TypeError` anywhere in it gives
    `None`.
  - `install_thread_crash_hook(command: str, root: Path | None = None) -> Callable[[], None]` —
    sets `threading.excepthook` to a hook that writes a report for `args.exc_value` with the
    command `f"{command} (thread {args.thread.name if args.thread else 'unknown'})"`, skips a
    `SystemExit`, and then calls the hook it replaced; answers a function that restores that hook.
  - `recent_crash_reports(root: Path | None = None, *, now: datetime | None = None, days: int =
    CRASH_RECENT_DAYS) -> list[Path]` — the `*.md` files of `crash_reports_dir(root)` modified
    within `days` of `now`, newest first; a missing folder gives `[]`.
