# Plan — F051 Escalate instead of block (unattended)

## Goal
An unattended run never stalls on the first human question: a task
that needs a decision pauses only its branch (needs_decision outcome
→ one decision on the EXISTING queue + awaiting-decision marking),
the executor keeps pulling ready tasks from disjoint branches and
picks up answered branches at batch boundaries, and open decisions
surface FIRST in status/report with the exact answer command. DONE
per docs/roadmap/features/T1_F051.md: the three-branch fixture (one
decision-blocked, two free) finishes the free work, ends blocked
with the open decision listed, and answer + resume completes the
rest.
