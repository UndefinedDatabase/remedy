### C2 — `F199 R3 C2: the health checks of the snapshots, the worktrees and the providers (T001)`
Paths: `packages/orchestration/self_health.py`, `apps/cli/command_catalog_doctor.py`. In

- `SNAPSHOT_SAMPLE: int = 20` and `SNAPSHOT_HINT: str = "run `remedy snapshot inspect <job id>
  <snapshot id>` for each named snapshot, whose two ids are the folder names in its path; a
  damaged snapshot cannot restore the files it recorded, so no revert should rely on it"`.
- `check_snapshot_manifests(root: Path | None = None, sample: int = SNAPSHOT_SAMPLE) ->
  HealthCheckResult`, check `snapshots`. The data root is `root`, else `resolve_data_root()`. The
  manifests are `data_root.glob(f"workspaces/*/{_SNAPSHOT_DIR_NAME}/*/manifest.json")`, sorted by
  `(st_mtime, str(path))` descending, the first `sample` of them. None gives PASS `"no workspace
  snapshot exists yet"`. Each is read by `_check_snapshot_integrity(manifest.parent)` (both names
  imported from `repository_snapshot`). Its problems, in this order and joined by `", "`: `"its
  manifest does not match its recorded hash"` when `manifest_ok` is false; `f"{n} recovery files
  missing"` when `blobs_missing` is n > 0; `f"{n} recovery files changed"` when
  `hash_mismatches` is n > 0. Any problem gives FAIL, detail `f"{bad} of {checked} newest
  workspace snapshots failed their hash check: "` followed by `f"{rel} ({problems})"` per bad
  snapshot joined by `"; "`, where `rel` is the snapshot folder relative to the data root in
  POSIX form, hint `SNAPSHOT_HINT`. Else PASS `f"{checked} of {checked} newest workspace
  snapshots passed their hash check"`.
- `WORKTREE_HINT: str = "run `git worktree prune` in each named repository; it forgets the
  worktrees whose folders are gone and changes no other file"`.
- `check_worktrees() -> HealthCheckResult`, check `worktrees`. The repositories are, over
  `_list_projects_readonly()` in its order, each project's `canonical_repo_path` when set, else
  its `repo_paths`; duplicates and paths that are not existing folders are dropped. None gives
  PASS `"no registered project has a repository on this machine"`. For each, `list_worktrees(repo)`;
  a `WorktreeError`, an `OSError` or a `subprocess.SubprocessError` puts the repository on an
  unreadable list. A record carrying the key `prunable` is named `f"{repo}: {record['worktree']}"`.
  Any named gives WARN, detail `f"{n} worktrees git calls prunable, their folders gone: "` + the
  names joined by `"; "`, hint `WORKTREE_HINT`; else PASS `f"{m} repositories checked; no
  worktree is prunable"` (m the repositories read). An unreadable list, when non-empty, adds to
  either detail `f"; git could not read {k} repositories: "` + their paths joined by `", "`.
- `PROVIDER_HINT: str = "install the Claude Code command line (claude) or Ollama, or set
  ANTHROPIC_API_KEY; `remedy worker doctor` checks a worker's own tooling"`.
- `check_providers(which: Callable[[str], str | None] | None = None, environ: Mapping[str, str] |
  None = None) -> HealthCheckResult`, check `providers`; `which` defaults to `shutil.which`,
  `environ` to `os.environ`. In this order: `claude-cli` is reachable when `which("claude")` is not
  None, else its gap is `"claude-cli needs the claude command on the path"`; `claude` when
  `environ.get("ANTHROPIC_API_KEY", "").strip()` is non-empty, else `"claude needs
  ANTHROPIC_API_KEY set"`; `ollama` when `which("ollama")` is not None, else `"ollama needs the
  ollama command on the path"`. The key's value is never put in any text. None reachable gives
  WARN, detail `"no provider can be reached: "` + the three gaps joined by `"; "`, hint
  `PROVIDER_HINT`. Else PASS, detail `"reachable: "` + the reachable names joined by `", "`,
  then `"; not reachable: "` + the unreachable names joined by `", "` when there are any, then
  `"; no provider was called"`. Never FAIL (DECISION F199 D2).
- `run_health_checks(root=None)` answers, in this order: `check_config_coherence()`,
