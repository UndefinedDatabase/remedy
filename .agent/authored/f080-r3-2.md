- **Parser** (packages/orchestration/roadmap_index.py, T001):
  build_index(repo_root) mirrors docs/roadmap/ROADMAP.md,
  docs/roadmap/features/*.md and docs/roadmap/STATUS.md into
  RoadmapIndex {features, milestones, order, inconsistencies} —
  schema roadmap_index/v1. Parse anchors are the documented header

  RoadmapGrammarError carries EVERY violation of one pass, each

  fixtures: missing/mismatched title line, malformed dependency line,
  unclosed bold block, tier disagreement, duplicate feature id,
  unknown status glyph, non-checkbox STATUS list item, duplicate
  STATUS line. The index is written to
  `<data_root>/roadmap/index.json` — one-way mirror, regenerated on
  every read path, never committed, never writing markdown and never
  checking a checkbox (A4 intact).
