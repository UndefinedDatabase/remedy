### C2 — subject `F253 R19 C2: the operator writes client tokens and their policy into api/clients.json`
NEW `packages/orchestration/api_clients.py`, its module docstring naming DECISION F253 D16 and
stating the file's place, its shape and the fail-closed rule of D16 (2). It holds:
- `API_CLIENTS_FILE_NAME = "clients.json"` and `API_CLIENT_TOKEN_MIN_LENGTH = 32`.
- `ApiClient`, a frozen dataclass: `name: str`, `token: str` declared with `field(repr=False)` so
  that no `repr` shows it, `projects: tuple[str, ...]`, `max_total_tokens: int | None`,
  `max_provider_calls: int | None`, `may_apply: bool`.

  the file name.
- `load_api_clients(root: Path | None = None) -> tuple[ApiClient, ...]`: the clients the file
  holds, in its order; `()` when the file is missing, when its mode lets group or others read or
  write it (`st_mode & 0o077`), when it cannot be read or decoded as UTF-8, when it is not JSON,
  and when any part of it is outside D16 (1): the top level an object whose only key is
  `clients`, that a list, each entry an object with exactly the six keys, `name` a non-empty
  string, `token` a string of at least `API_CLIENT_TOKEN_MIN_LENGTH` characters, `projects` a list
  of non-empty strings, each ceiling `None` or an `int` above zero that is not a `bool`,
  `may_apply` a `bool`, and no two entries sharing a name or a token. It never raises for the
  file's content or for an `OSError`; every `except` names its exception classes.
- `match_api_client(supplied: str, clients: Sequence[ApiClient]) -> ApiClient | None`: the client
  whose token equals SUPPLIED, compared as UTF-8 bytes with `secrets.compare_digest` against every
  client; `None` for the empty string and for no match.
- `client_order_refusal(client: ApiClient, project_keys: Iterable[str], max_total_tokens: str |
  None, max_provider_calls: str | None) -> str | None`: `None` when the order is inside the
  client's policy, otherwise one sentence naming the client, the reason and ending "; nothing was
  run". Outside means: no key of PROJECT_KEYS is in `client.projects`; or for a ceiling that is not
  `None`, the matching cap is `None`, is refused by `_pos_int` (catch `BudgetConfigError`), or is
  above the ceiling. The sentence names the header key the cap is written under
  (`max-total-tokens:` or `max-provider-calls:`).
