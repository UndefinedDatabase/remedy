### C3 — `F303 R4 C3: the MCP protocol core, closed by default (DECISION F303 D4)`
Paths: `packages/orchestration/mcp_server.py` (NEW FILE), `tests/test_no_orphan_modules.py`
(`ALLOWED_UNWIRED` gains it in sorted position with the reason
`"F303's MCP protocol core; round 5's client mcp command wires it (DECISION F303 D4)"`).
1. Module docstring, two short paragraphs: what it is (the stdio transport of the Model Context
   Protocol, JSON-RPC 2.0, one message per line, DECISION F303 D4) and that it is closed by
   default: it offers only the tools the person starting it names. Standard library only. A
   one-line WHY comment above each public definition. No blind `except Exception`.
2. Public names, exactly: `MCP_PROTOCOL_VERSION = "2025-06-18"`; `MCP_SERVER_NAME = "remedy"`;
   the error codes `MCP_PARSE_ERROR = -32700`, `MCP_INVALID_REQUEST = -32600`,
   `MCP_METHOD_NOT_FOUND = -32601`, `MCP_INVALID_PARAMS = -32602`; `McpServerError(Exception)`;
   `McpTool`, a frozen dataclass: `name: str`, `description: str`, `input_schema: Mapping[str, Any]`,
   `call: Callable[[dict[str, Any]], dict[str, Any]]`.
3. `serve_mcp(reader: TextIO, writer: TextIO, tools: Sequence[McpTool], allowed: Collection[str], *, version: str) -> int`:
   (a) Before reading: refuse with `McpServerError` a repeated tool name in `tools`, and every name
       in `allowed` that no tool has, naming it: `f"no MCP tool is named {name!r}; the tools are: {', '.join(sorted(names))}"`.
   (b) Then for each line of `reader` (blank lines skipped): parse it as JSON; on failure answer
       `{"jsonrpc": "2.0", "id": None, "error": {"code": MCP_PARSE_ERROR, "message": "the line is not JSON"}}`.
       A value that is not an object, whose `jsonrpc` is not `"2.0"` or whose `method` is not a
       string answers `MCP_INVALID_REQUEST` with the message's `id` when it is a string or an
       integer, else None. A message without an `id` key is a notification: nothing is written,
       whatever its method.
   (c) Methods: `initialize` → `{"protocolVersion": MCP_PROTOCOL_VERSION, "capabilities": {"tools": {}}, "serverInfo": {"name": MCP_SERVER_NAME, "version": version}}`;
       `ping` → `{}`; `tools/list` → `{"tools": [{"name", "description", "inputSchema"} for each allowed tool, sorted by name]}`;
       `tools/call` → params must be an object whose `name` is an allowed tool and whose
       `arguments`, when present, is an object; otherwise `MCP_INVALID_PARAMS` with the message
       `f"the tool {name!r} is not offered by this server"` for a name that is not allowed (an
       unknown one included) and `"the arguments must be an object"` for the arguments. The tool's
       `call(arguments or {})` gives the answer; the result is
       `{"content": [{"type": "text", "text": json.dumps(answer, sort_keys=True, ensure_ascii=False)}], "structuredContent": answer, "isError": answer.get("ok") is False}`.
       Any other method → `MCP_METHOD_NOT_FOUND` with `f"unknown method {method!r}"`.
   (d) Each answer is `json.dumps(..., ensure_ascii=False)` plus `"\n"`, written and flushed at once.
   (e) Returns 0 at the end of input.

reader and writer and two stand-in tools (`echo`, answering `{"ok": True, "got": arguments}`, and
`fails`, answering `{"ok": False, "error": "x"}`). Tests, each named for what it proves:
(a) `initialize`, then `notifications/initialized` (no answer), then `tools/list` with both allowed

(b) closed by default: `allowed=()` → `tools/list` answers `[]` and every `tools/call` -32602;
(c) only allowed tools are listed and callable: `allowed={"echo"}` → `fails` neither listed nor
    callable;
(d) a call's result: `content` text equals `json.dumps(answer, sort_keys=True)` parsed back,
    `structuredContent` equals the answer, `isError` false for `echo` and true for `fails`;
(e) the refusals, one parametrized case each, with readable ids: a line that is not JSON (-32700,
    null id), a JSON array, `jsonrpc` `"1.0"`, a missing method (each -32600), an unknown method
    (-32601), `arguments` a list and an unknown tool (each -32602); each answer carries the
    request's id where it had one;
(f) a notification with an unknown method writes nothing; `ping` answers `{}`;
(g) `McpServerError` for an allowed name no tool has, and for two tools of one name, before
    anything is written;
(h) the return value is 0 and a blank line is skipped.
