`packages/orchestration/public_api.py`:
1. `PUBLIC_API_VERSION = "1.1"`. The module docstring adds one paragraph on the ledger (D2 (1)).
2. `PublicApiRoute` gains, after `deprecated`, `twin_key: str | None = None` (the key of the
   twin's `--json` answer this route answers, None for the whole answer) and
   `query: tuple[str, ...] = ()` (the query keys the route accepts, each a flag whose value is
   `true` or `false`), each with a one-line comment.
3. A second route after the first: method `GET`, path `/api/v1/digest`, twin `status.run`,
   `twin_key` `"client"`, `query` `("all_ended_jobs",)`, description "The digest a program reads
   about once a minute: every project with its missions, the jobs that still need something and
   the last ended ones, every open decision and the jobs waiting for their apply, as the `client`
   object of `remedy status --json` holds it; `all_ended_jobs=true` lists every ended job, as
   `--all-ended-jobs` does."
4. `answer_public_api_get(path: str, query: str = "")` takes the RAW query string and parses it
   itself with `urllib.parse.parse_qs(query, keep_blank_values=True)`. Order: the route is found
   first (404 `api_route_not_found` as today); then the query: a key the route does not declare, a
   key given more than once, or a value other than `true` or `false` answers
   `(400, build_error("api_query_invalid", <a sentence naming the key and the keys the route
   accepts>), {})`; then the twin's answer, its function now called with the parsed flags as
   keyword arguments named after the keys (`all_ended_jobs: bool`). The digest's function returns
   `build_ok(**build_client_digest(every_ended_job=all_ended_jobs))`, the call `_cmd_status` makes
   under `--json` for its `client` key.
5. `append_public_api_call(*, token_fp: str, method: str, path: str, status: int, error: str,
   root: Path | None = None) -> None`: appends ONE line, `json.dumps` of the record with exactly
   the keys `ts` (UTC, `YYYY-MM-DDTHH:MM:SSZ`), `token_fp`, `method`, `path`, `status`, `error`
   in that order and no indentation, plus `\n`, to `data_class_dir("api", root) / "calls.jsonl"`.
   The directory is created with mode 0o700 and the file opened with
   `os.open(..., os.O_WRONLY | os.O_CREAT | os.O_APPEND, 0o600)` and written with ONE `os.write`,
   so concurrent requests never interleave a line. It raises `OSError` on failure; it catches
   nothing itself. A module constant names the file, `PUBLIC_API_LEDGER_NAME = "calls.jsonl"`.
6. The page renderer: the route table gains a `Query` column after `Path` (each key backticked,
   `—` when none), and `Answers as` reads, for a route with a `twin_key`, the twin's command line
   followed by `, its \`client\` object` (the key read from the route, not typed).
