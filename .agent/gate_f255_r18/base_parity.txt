  while copytree preserved the primary's older mtime on the copied
  apps/ui/dist/index.html. Measured in the base worktree:
    newest apps/ui/src mtime_ns   1787279477444570086
    dist/index.html mtime_ns      1787279383323951913 (as copied)
  src NEWER than dist => _frontend_is_stale() True => _auto_build_frontend
  returns None immediately because REMEDY_UI_NO_AUTO_BUILD=1 => _load_frontend
  falls through to its loud failure, "ERROR: React UI not built.", which is
  captured on stderr under each of the eight failing ui_server ids.
  The neutralisation therefore WORKED as code - the base log contains 0 lines
  matching "auto-build (" so no npm install and no npm run build was launched
  by that path - and the parity copy is what left the artifact looking stale.
  This is the artifact class the R-0155 amendment describes, reached by mtime
  rather than by absence.
