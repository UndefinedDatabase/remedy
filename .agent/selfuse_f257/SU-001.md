# Job: Document the Markdown job-file format

## Task 1
Write one new page under `docs/` describing the Markdown job-file format that
`packages/orchestration/pingpong_job.py:parse_job_file` accepts, so a reader
looking for the format finds it where the documentation index sends them.

The page states, at minimum: the `# Job: <title>` H1 that names the job; the
`## Task N` headings that split the file into tasks; and the `Acceptance:` line
that separates a task's body from its acceptance criteria. Describe what the
parser really does rather than what a reader might assume — task ids are
assigned by parse order (T001, T002, ...) and not by the heading number, which
is kept separately. Cite the parser by path so the page can be checked against
the code it describes.

Register the new page in the `docs/README.md` index with its category, a
one-line description and a status marker, the way AGENTS.md's Documentation
Updates rules require of every new ist-doc.

Acceptance:
- A new page under `docs/` describes the job-file format, naming the `# Job:` H1, the `## Task N` headings and the `Acceptance:` line.
- That page is registered in the `docs/README.md` index with a category, a one-line description and a status marker.
