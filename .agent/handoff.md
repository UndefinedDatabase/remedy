at, and they only read that setting — they never change it just by asking. If the mission loop is
waiting on you because of the level, the overview now says so and tells you the exact next command

waits for you, and every attempt is written down either way. Nothing here changes what happens at
today's default level. Everything this round touched was re-run end to end and came back clean.
